원본을 python-docx로 `word/document.xml`까지 직접 파싱하여 1,121개 검토항목 전체(순서·일련번호·제목·세부내용)를
전수 대조 검증한 결과, 순서·일련번호는 100% 일치하였고 통합본 자체의 실제 오류 5건(테이블 27/31/33/05/45)은
발견 즉시 수정하여 커밋하였다. 그 수정 이후에도 남아있는 차이는 아래 3건뿐이며, 모두 **원본 v0.44.docx 쪽의
오탈자**로 확인되었다. 통합본은 이미 정정된(더 정확한) 표현을 담고 있어 별도로 수정하지 않았다.

## 조치 안내

- 통합본(`_전체_통합_출처근거조사.md`)과 각 개별 table 파일(`table_02`, `table_03`, `table_39`)은 이미 정정된
  표현으로 작성되어 있어 **추가 조치가 필요하지 않다.**
- 원본 문서 자체를 완전히 일치시키고 싶다면, 위 표의 "원본(v0.44.docx)" 열에 표시된 3곳을 v0.44.docx에서
  직접 수정하면 된다. 수정 시 알려주시면 재검증하여 본 문서를 갱신하겠다.

## 검증 방법

1. `word/document.xml`을 `zipfile` + `xml.etree.ElementTree`로 직접 파싱하여 54개 표의 모든 행에서
   일련번호(`[N-N-가-N-NN]` 형식)·제목·세부내용(검토내용 불릿)을 순서대로 추출 (python-docx 라이브러리 병행 사용)
2. `_전체_통합_출처근거조사.md`에서 동일한 방식으로 `#### [ID]: 제목`과 그 아래 `* **검토 내용**:` 블록의
   불릿 목록을 추출
3. 두 목록을 인덱스 순서대로 1:1 대조 — 총 개수, 순서, ID, 테이블 매핑, 제목, 세부내용 불릿 텍스트 일치 여부 확인
   (공백 정규화·`·`/`・` 문자 통일 등만 정규화, 그 외 원문 그대로 비교)
4. 불일치 발견 시 원본 XML의 텍스트 런(run) 단위까지 재확인하여 통합본 측 오류인지 원본 측 오탈자인지 판별
