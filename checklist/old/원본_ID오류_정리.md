# 감리 점검항목 원본 문서 ID 오류 정리

작성 목적: 원본 문서(`감리 점검항목(클라우드, 운영 및 유지보수, 생성형 AI)_v0.41.docx` → `checklist/extracted_tables/table_XX.md`로 추출)에서 발견된 일련번호/ID 오류를 정리. 출처근거조사 결과물(`checklist/output/table_XX_출처근거조사.md`) 작성 중 항목 개수 검증(원본 1,099개 vs 결과물 1,125개) 과정에서 발견됨.

전체 차이 26건 = 아래 오류들로 100% 설명됨 (누락된 항목 없음, 반대로 원본 자체의 번호 오류로 인해 결과물에서 항목이 분리되어 늘어난 것).

**오류 유형**:
- **A. 대괄호 ID 자체가 누락**된 경우 (1개 파일, 2건)
- **B. 같은 섹션 안에서 일련번호가 중복 부여**되어 서로 다른 두 문항이 같은 ID를 갖게 된 경우 (12개 파일, 24건)
- **C. (table_21 한정) 카테고리 셀 안에 서로 다른 두 개의 문항 묶음이 존재하는데, 그룹 번호(1,2,3...)가 초기화되지 않고 재사용되어 앞부분과 충돌** — 추가로 ID 표기 오탈자(공백, 자모 오류) 다수 포함
- **D. (table_27 한정) 섹션 2의 문항들이 그룹번호 "1"로 잘못 표기되어 섹션 1과 충돌**
