## 1. 신규·변경 서비스 운영지원 결과 확인
- 01. 신규 또는 변경 서비스의 운영지원이 적정하게 수행되었는가? [2-3-다-1-01]
- 신규·변경 서비스의 운영 인수 조건 충족 여부
- 서버, 네트워크, 보안정책, 백업, 모니터링 설정 지원 결과 확인
- 운영 전환 승인 및 인수 증적 확인
- 02. 운영 readiness 점검이 완료되었는가? [2-3-다-1-02]
- 구성정보, 계정정보, 접근경로, 모니터링 항목 인수 여부
- 서버 기동, 네트워크 연결, 접근권한, 백업, 로그수집 정상성 확인
- readiness 미충족 항목의 보완 및 재검증 결과 확인
## 2. 서비스수준 관리 결과 확인
- 01. 인프라 운영 SLA가 목표 수준을 충족하였는가? [2-3-다-2-01]
- 가용성, 장애처리시간, 복구시간, 성능, 용량 지표 실적 확인
- 서버, 네트워크, DB, 스토리지, 보안장비별 SLA 달성 여부
- SLA 미달 항목의 원인분석 및 개선조치 여부
- 02. SLA 측정 결과가 신뢰성 있게 산정·보고되었는가? [2-3-다-2-02]
- 측정 데이터 원천, 산정 방식, 예외처리 내역 확인
- 운영보고서와 SLA 실적 간 정합성 확인
- 서비스수준 미달 예외 승인 여부 확인
## 3. 서비스 보고 결과 확인
- 01. 인프라 운영상태와 서비스수준 보고가 계획대로 수행되었는가? [2-3-다-3-01]
- 일일·주간·월간 운영보고서 작성 여부
- 장애, 성능, 용량, 변경, 보안, 백업, 점검 결과 보고 여부
- 보고 대상, 보고 주기, 승인 절차 준수 여부
- 02. 보고자료가 실제 운영이력과 일치하는가? [2-3-다-3-02]
- 모니터링 결과, 장애관리시스템, 변경관리시스템 자료와 보고서 비교
- SLA 실적과 운영보고 간 불일치 여부
- 수작업 집계 항목의 검증 및 승인 여부
## 4. 서비스 연속성 및 가용성 관리 결과 확인
- 01. 서비스 연속성 및 가용성 목표가 충족되었는가? [2-3-다-4-01]
- 주요 시스템별 가용성 실적 확인
- 장애 허용 기준, 서비스 중단 허용시간 준수 여부
- 이중화, 장애전환, 백업·복구, DR 연계 운영 결과 확인
- 02. 장애 또는 재해 상황의 복구 절차가 검증되었는가? [2-3-다-4-02]
- RTO, RPO, 복구 소요시간, 데이터 손실 여부 확인
- 복구 후 정상성 검증 및 승인 여부
- 복구훈련 또는 모의훈련 결과와 개선조치 확인
## 5. 용량관리 결과 확인
- 01. 인프라 자원 용량이 기준에 따라 관리되었는가? [2-3-다-5-01]
- CPU, 메모리, 디스크, 스토리지, 네트워크, DB 사용률 확인
- 임계치 초과, 용량 부족, 피크 사용량 관리 이력 확인
- 증설 요청, 승인, 반영 결과 확인
- 02. 용량 부족 또는 과다 할당에 대한 조치가 수행되었는가? [2-3-다-5-02]
- 용량 부족 예측 및 사전 경보 이력 확인
- 미사용 또는 과다 할당 자원 회수 여부
- 용량관리 결과의 비용관리 및 SLA 연계 여부
## 6. 정보보안관리 결과 확인
- 01. 인프라 운영 보안관리 활동이 적정하게 수행되었는가? [2-3-다-6-01]
- 계정관리, 접근통제, 권한점검, 보안패치, 취약점 조치 이력 확인
- 서버, 네트워크, DB, 보안장비, 클라우드 자원별 보안관리 결과 확인
- 보안로그, 작업로그, 접속로그 수집·보관 여부
- 02. 운영자 및 외부 유지관리 인력 접근통제가 준수되었는가? [2-3-다-6-02]
- 관리자 권한 부여·변경·회수 이력 확인
- 원격접속, VPN, 접근통제시스템 사용 이력 확인
- 외부 인력 작업 승인, 작업기록, 계정 회수 여부
## 7. 비즈니스 관계 및 공급자관리 결과 확인
- 01. 업무부서와의 서비스 요구사항 관리가 적정하게 수행되었는가? [2-3-다-7-01]
- 업무부서 요청 접수, 우선순위, 승인, 반영 이력 확인
- 서비스 변경 요청의 운영 영향도 검토 여부
- 사용자 만족도 또는 서비스 개선 요청 반영 여부
- 02. 외부 공급자 운영지원이 계약 및 SLA 기준에 따라 수행되었는가? [2-3-다-7-02]
- CSP, MSP, 통신사, 상용SW 공급사, 장비 공급사 지원 이력 확인
- 장애, 패치, 기술지원, 긴급지원 요청 처리 결과 확인
- 공급자 SLA와 발주기관 SLA 간 불일치 또는 책임공백 여부
## 8. 인시던트 및 서비스 요청관리 결과 확인
- 01. 인시던트와 서비스 요청이 기준에 따라 처리되었는가? [2-3-다-8-01]
- 인시던트, 서비스 요청, 장애, 문의, 작업요청 분류 이력 확인
- 접수, 분류, 배정, 조치, 확인, 종료 절차 준수 여부
- 우선순위, 처리기한, 보고기준 준수 여부
- 02. 서비스 요청 처리 결과가 추적관리되었는가? [2-3-다-8-02]
- 요청 이력, 처리결과, 승인, 사용자 확인 증적 확인
- 미처리·보류·반려 요청의 사유와 후속계획 확인
- 서비스 요청 처리율과 SLA 연계 여부
## 9. 문제관리 결과 확인
- 01. 반복 장애와 근본원인 해결을 위한 문제관리가 수행되었는가? [2-3-다-9-01]
- 문제 등록, 우선순위, 담당자, 조치기한 관리 여부
- 근본원인 분석, 개선조치, 재발방지 대책 수립 여부
- 장기미결 문제의 보고 및 의사결정 이력 확인
- 02. 문제관리 결과가 운영 개선으로 연계되었는가? [2-3-다-9-02]
- 문제 해결 결과의 변경관리·릴리즈관리 연계 여부
- 재발방지 조치의 효과 측정 여부
- 문제관리 결과의 운영보고 반영 여부
## 10. 구성관리 결과 확인
- 01. 인프라 구성정보가 최신 상태로 관리되고 있는가? [2-3-다-10-01]
- 서버, 네트워크, DB, 스토리지, 보안장비, 클라우드 자원 구성정보 확인
- 구성정보 변경 시 갱신 및 승인 이력 확인
- CMDB 또는 구성관리대장 최신화 여부
- 02. 구성정보와 실제 운영환경 간 정합성이 확인되었는가? [2-3-다-10-02]
- 정기 구성정보 점검 결과 확인
- 변경 이력과 구성정보 최신본 간 비교 결과 확인
- 구성정보 오류 또는 누락 보정 결과 확인
## 11. 변경 및 릴리즈관리 결과 확인
- 01. 인프라 변경 및 릴리즈가 통제된 절차에 따라 수행되었는가? [2-3-다-11-01]
- 변경요청, 영향도 분석, 승인, 반영, 검증, 종료 이력 확인
- 정기변경, 긴급변경, 표준변경 구분 관리 여부
- 네트워크, 서버, DB, 보안정책 변경 승인 여부
- 02. 변경 실패에 대비한 원복 및 사후조치가 수행되었는가? [2-3-다-11-02]
- 변경 전 백업, 변경 후 정상성 점검 수행 여부
- 변경 실패 시 보고, 복구, 재승인 절차 수행 여부
- 변경 결과와 구성정보 갱신 연계 여부
## 12. 운영상태관리 결과 확인
- 01. 인프라 운영상태가 상시 점검·관리되었는가? [2-3-다-12-01]
- 서버, 네트워크, DB, 스토리지, 보안장비 상태 점검 결과 확인
- 모니터링 항목, 임계치, 알림, 조치 이력 확인
- 정기점검, 예방점검, 긴급점검 수행 여부
- 02. 운영상태 이상 징후에 대한 조치가 수행되었는가? [2-3-다-12-02]
- 성능저하, 용량부족, 장애징후, 보안이벤트 탐지 이력 확인
- 이상 징후 발생 시 조치, 보고, 개선 결과 확인
- 운영상태 점검 결과의 서비스보고 및 개선관리 연계 여부
