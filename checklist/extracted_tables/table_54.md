- 01. 인프라 장비 및 솔루션이 계획대로 도입·설치되었는가? [3-3-바-1-01]

- 02. 개발·검증·운영 환경이 계획대로 구축되었는가? [3-3-바-1-02]
- 개발·검증·운영 환경 분리 구성 여부
- 환경별 서버, DB, 네트워크, 보안정책 적용 여부
- 환경 간 데이터 및 접근통제 기준 준수 여부
- 03. 인프라 구성 결과가 설계 산출물과 일치하는가? [3-3-바-1-03]
- 인프라 구성도, 네트워크 구성도, 장비목록과 실제 구성 비교
- IP, 포트, 방화벽, 라우팅, 보안정책 설정 결과 확인
- 변경된 구성항목의 승인 및 형상관리 반영 여부
## 2. 성능·용량 및 병목 검증
- 01. 인프라 성능이 요구 기준을 충족하는가? [3-3-바-2-01]

- 03. CPU/GPU/메모리/스토리지 용량이 적정한가? [3-3-바-2-03]
- 모델 추론, 임베딩, 벡터검색 부하 시 자원 사용률 확인
- 데이터 증가량, 로그 저장량, 백업용량 반영 여부 확인
- 피크 시간대 처리량 및 자원 여유율 확인
- 03. 병목구간이 식별·조치되었는가? [3-3-바-2-03]
- GPU, 벡터DB, 네트워크, API Gateway 병목구간 확인

- 병목구간 개선조치 및 재시험 결과 확인
