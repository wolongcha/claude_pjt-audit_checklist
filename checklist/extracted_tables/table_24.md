# Table 24
- 도메인: 2. 운영 및 유지관리 사업
- 단계: 1. 요구정의 단계
- 카테고리: 바. 인프라 유지관리

## 1. 인프라 유지관리 대상 및 범위 정의
- 01. 인프라 유지관리 대상이 명확하게 식별되어 있는가? [2-1-바-1-01]
- 서버, 스토리지, 네트워크, DB, 보안장비, 백업장비, 클라우드 자원 식별 여부
- 장비명, 위치, 모델, 버전, 용도, 담당자, 유지관리 계약정보 확인
- 유지관리 제외 대상과 제외 사유 확인
- 02. 인프라 유지관리 범위가 명확하게 정의되어 있는가? [2-1-바-1-02]
- 정기점검, 장애처리, 패치, 부품교체, 설정변경, 기술지원 범위 확인
- 예방점검, 긴급점검, 성능점검, 보안점검 포함 여부
- 운영업무와 유지관리업무 간 경계 확인
- 03. 인프라 중요도와 우선순위가 정의되어 있는가? [2-1-바-1-03]
- 핵심 서버, 주요 DB, 대외서비스 장비, 보안장비 중요도 분류 여부
- 장애 발생 시 업무 영향도 분석 여부
- 우선 복구 대상과 우선 지원 대상 정의 여부
## 2. 정기·
예방점검 요구사항
- 01. 인프라 정기점검 기준이 정의되어 있는가? [2-1-바-2-01]
- 서버, DB, 네트워크, 스토리지, 보안장비별 점검항목 정의 여부
- 점검 주기, 점검 담당자, 점검 결과보고 기준 확인
- 점검 결과 이상 발생 시 조치절차 정의 여부
- 02. 예방점검 및 긴급점검 기준이 마련되어 있는가? [2-1-바-2-02]
- 장애징후, 성능저하, 용량부족, 보안위험 탐지 기준 확인
- 예방조치 대상과 조치 승인 기준 확인
- 긴급점검 수행 조건과 보고 기준 정의 여부
- 03. 점검 결과의 개선조치 연계 기준이 정의되어 있는가? [2-1-바-2-03]
- 점검 결과의 조치계획 수립 기준 확인
- 반복 이상 징후의 문제관리 전환 기준 확인
- 조치 결과의 운영보고 반영 기준 확인
## 3. 장애·
성능·용량 관리 요구사항
- 01. 인프라 장애관리 기준이 정의되어 있는가? [2-1-바-3-01]
- 장애 등급, 접수경로, 조치시간, 보고체계 정의 여부
- 서버, DB, 네트워크, 스토리지, 보안장비별 장애분류 기준 확인
- 중대장애 발생 시 비상연락망과 escalation 기준 확인
- 02. 성능관리 기준이 정의되어 있는가? [2-1-바-3-02]
- CPU, 메모리, 디스크 I/O, 네트워크, DB 성능지표 정의 여부
- 성능 임계치, 알림 기준, 조치 기준 확인
- 성능저하 원인분석 및 개선조치 기준 정의 여부
- 03. 용량관리 기준이 정의되어 있는가? [2-1-바-3-03]
- 디스크, 스토리지, DB, 로그, 백업 용량 임계치 확인
- 용량 증가 추세 분석과 증설 기준 정의 여부
- 용량 부족 또는 과다 할당에 대한 조치 기준 확인
## 4. 백업·복구 및 가용성 유지관리
- 01. 백업·복구 유지관리 기준이 정의되어 있는가? [2-1-바-4-01]
- 백업 대상, 백업 주기, 보관기간, 보관 위치 정의 여부
- 백업 실패 시 알림 및 재수행 기준 확인
- 복구시험 대상, 주기, 결과보고 기준 정의 여부
- 02. 가용성 유지관리 요구사항이 정의되어 있는가? [2-1-바-4-02]
- 이중화, 장애전환, 클러스터, DR 연계 대상 확인
- 장애전환 시험 및 복구 검증 필요성 확인
- RTO, RPO, 복구 우선순위 기준 확인
- 03. 장애 또는 복구 실패 시 대응 기준이 마련되어 있는가? [2-1-바-4-03]
- 복구 실패 시 보고, 원인분석, 재복구 절차 정의 여부
- 대체 장비, 예비 자원, 공급사 긴급지원 기준 확인
- 복구 후 서비스 정상성 검증 기준 확인
## 5. 구성·
변경·보안 유지관리
- 01. 인프라 구성정보 관리 기준이 정의되어 있는가? [2-1-바-5-01]
- 서버, 네트워크, DB, 보안장비 구성정보 관리 항목 정의 여부
- 구성 변경 시 구성관리대장 또는 CMDB 갱신 기준 확인
- 실제 운영환경과 구성정보 간 정합성 점검 기준 확인
- 02. 인프라 변경관리 기준이 정의되어 있는가? [2-1-바-5-02]
- 변경요청, 영향도 분석, 승인, 반영, 검증, 종료 절차 확인
- 정기변경, 긴급변경, 표준변경 구분 기준 확인
- 변경 실패 시 원복 및 재승인 기준 정의 여부
- 03. 인프라 보안 유지관리 기준이 정의되어 있는가? [2-1-바-5-03]
- 계정권한, 접근통제, 보안패치, 취약점 조치 기준 확인
- 보안로그, 작업로그, 접속로그 관리 기준 확인
- 외부 유지관리 인력 접근통제 및 작업승인 기준 확인
