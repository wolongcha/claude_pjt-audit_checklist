## 1. 상용SW 유지관리 대상 정의
- 01. 상용SW 유지관리 대상이 누락 없이 식별되어 있는가? [2-1-마-1-01]
- 제품명, 버전, 설치 위치, 사용 업무, 라이선스 정보 확인
- WAS, DBMS, 검색엔진, 리포팅, 보안솔루션, 모니터링 도구 등 대상 식별 여부
- 유지관리 제외 제품과 제외 사유 확인
- 02. 상용SW별 유지관리 범위가 명확하게 정의되어 있는가? [2-1-마-1-02]
- 장애지원, 기술문의, 패치, 업그레이드, 재설치, 이전 지원 범위 확인
- 공급사 지원 범위와 수행사 지원 범위 구분 여부
- 무상지원, 유상지원, 별도 계약 대상 구분 여부
- 03. 상용SW가 업무서비스와 어떻게 연계되는지 파악되어 있는가? [2-1-마-1-03]
- 상용SW 사용 업무와 연계 시스템 식별 여부
- 상용SW 장애 시 업무 영향도 분석 여부
- 핵심 상용SW의 우선 대응 기준 정의 여부
## 2. 라이선스 및 계약조건 관리
- 01. 상용SW 라이선스 조건이 명확하게 관리되고 있는가? [2-1-마-2-01]
- CPU, Core, 사용자 수, 서버 수, 인스턴스 기준 라이선스 확인
- 라이선스 만료일, 사용범위, 계약조건 확인
- 라이선스 초과 사용 또는 미계약 사용 가능성 점검
- 02. 유지관리 계약조건이 운영 요구사항을 충족하는가? [2-1-마-2-02]
- 장애지원 시간, 응답시간, 기술지원 범위 확인
- 패치, 업그레이드, 재설치, 이전 지원 포함 여부
- 공급사 SLA와 발주기관 SLA 간 정합성 확인
- 03. 상용SW 공급사 및 제조사 책임이 명확한가? [2-1-마-2-03]
- 공급사, 제조사, 수행사, 운영조직 간 역할 구분 여부
- 기술지원 요청·접수·조치·완료 절차 정의 여부
- 지원 불가 또는 지원 지연 시 대체 대응방안 확인

## 4. 장애처리 및 긴급변경 관리

- 제조사 패치 또는 버전 업그레이드 필요성 검토 기준 확인
- 제품 결함에 대한 공급사 조치 및 후속관리 기준 확인
