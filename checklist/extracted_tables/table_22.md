## 1. 유지관리 대상 및 범위 정의
- 01. 개발SW 유지관리 대상과 범위가 명확하게 정의되어 있는가? [2-1-라-1-01]
- 유지관리 대상 업무시스템, 프로그램, 화면, 배치, 인터페이스 식별 여부
- 오류수정, 기능개선, 성능개선, 사용자지원 등 유지관리 범위 정의 여부
- 유지관리 제외 대상과 제외 사유 명확성 확인
- 02. 운영과 유지관리의 업무 경계가 명확한가? [2-1-라-1-02]
- 단순 운영지원, 장애조치, 프로그램 수정, 기능개선 간 구분 기준 확인
- 개발SW 운영팀과 유지관리팀 간 책임분계 정의 여부
- 장애가 프로그램 수정으로 전환되는 기준 정의 여부
- 03. 유지관리 대상별 중요도와 우선순위가 정의되어 있는가? [2-1-라-1-03]
- 핵심 업무, 대민 서비스, 내부 업무별 중요도 분류 여부
- 장애 발생 시 업무 영향도 기준 정의 여부
- 우선 처리 대상 기능 및 업무 기준 정의 여부
## 2. 유지관리 계획 및 표준절차
- 01. 개발SW 유지관리 계획과 표준절차가 정의되어 있는가? [2-1-라-2-01]
- 유지관리 요청 접수, 분석, 승인, 수정, 테스트, 배포 절차 정의 여부
- 정기·비정기 유지관리 활동 기준 정의 여부
- 표준 개발·수정·검증 절차와 산출물 기준 정의 여부
- 02. 정기점검 및 예방점검 기준이 정의되어 있는가? [2-1-라-2-02]
- 프로그램 오류, 로그, 배치 실패, 연계 오류 점검 기준 확인
- 정기점검 주기, 담당자, 결과보고 기준 확인
- 예방점검 결과의 개선요청 전환 기준 확인
- 03. 유지관리 표준과 코딩·수정 기준이 마련되어 있는가? [2-1-라-2-03]
- 소스 수정 기준, 명명규칙, 주석, 배포파일 관리 기준 확인
- 보안코딩 및 취약점 조치 기준 반영 여부
- 수정 결과의 형상관리 반영 기준 확인
## 3. 요구사항 및 CSR 처리관리
- 01. 사용자 요구사항과 CSR 처리 기준이 정의되어 있는가? [2-1-라-3-01]
- 오류수정, 기능개선, 데이터 수정, 단순문의, 업무지원 요청 분류 기준 확인
- CSR 접수경로, 우선순위, 처리기한, 승인권자 정의 여부
- 반려, 보류, 이관 요청의 처리 기준 확인
- 02. CSR 처리 시 영향도 분석 기준이 마련되어 있는가? [2-1-라-3-02]
- 업무기능, 연계시스템, DB, 배치, 보안 영향 분석 기준 확인
- 수정 범위와 테스트 범위 결정 기준 확인
- 변경에 따른 원복 필요성 검토 기준 확인
- 03. CSR 처리 결과를 추적관리할 수 있는가? [2-1-라-3-03]
- 요청 접수부터 분석, 수정, 테스트, 배포, 종료까지 이력관리 여부
- 요청사항과 수정 산출물, 테스트 결과, 배포 결과 간 추적성 확보 여부
- 사용자 확인 및 종료 승인 기준 정의 여부
## 4. 프로그램 수정 및 테스트 요구사항
- 01. 프로그램 수정 요구사항이 명확하게 정의되어 있는가? [2-1-라-4-01]
- 수정 대상 기능, 화면, 배치, 인터페이스 식별 여부
- 수정 사유, 변경 범위, 영향 범위, 처리기한 정의 여부
- 긴급수정과 정기수정 구분 기준 확인
- 02. 수정 후 테스트 기준이 정의되어 있는가? [2-1-라-4-02]
- 단위시험, 통합시험, 회귀시험, 사용자 확인시험 대상 정의 여부
- 수정 기능과 영향 기능의 테스트 범위 정의 여부
- 결함 발생 시 조치·재시험·승인 기준 확인
- 03. 운영 반영 전 검증 및 승인 기준이 마련되어 있는가? [2-1-라-4-03]
- 테스트 결과서, 사용자 확인서, 배포 승인서 확보 기준 확인
- 중대 결함 발생 시 운영 반영 보류 기준 확인
- 배포 전 백업 및 배포 실패 시 원복 기준 정의 여부
## 5. 구성관리 및 릴리스·배포관리
- 01. 수정 프로그램의 형상 및 구성관리 기준이 정의되어 있는가? [2-1-라-5-01]
- 소스, 설정파일, 배포파일, 라이브러리 버전관리 기준 확인

- 변경 이력과 최종 반영본 관리 기준 확인
- 02. 릴리스 및 배포관리 기준이 정의되어 있는가? [2-1-라-5-02]
- 정기배포, 긴급배포, 임시배포 구분 기준 확인

- 03. 배포 실패 또는 장애 발생 시 원복 기준이 마련되어 있는가? [2-1-라-5-03]
- 배포 전 백업, 이전 버전 보관, 원복 절차 정의 여부
- 원복 판단 기준과 승인절차 확인
- 원복 후 정상성 검증 및 재배포 기준 확인
