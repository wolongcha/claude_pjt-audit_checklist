## 1. 릴리즈 및 배포관리 결과 확인
- 01. 개발SW 릴리즈 및 배포가 승인된 절차에 따라 수행되었는가? [2-3-나-1-01]
- 정기배포, 긴급배포, 운영반영 이력 확인
- 배포 승인, 배포 담당자, 배포 일시, 배포 대상 확인
- 승인되지 않은 배포 또는 임의 변경 여부 확인
- 02. 릴리즈·배포 전후 검증과 원복 준비가 적정하게 수행되었는가? [2-3-나-1-02]
- 배포 전 빌드, 테스트, 백업 수행 여부
- 배포 후 기능 정상성, 연계 정상성, 오류로그 확인 여부
- 배포 실패 시 원복 또는 재배포 절차 수행 여부
- 03. 릴리즈·배포 결과가 변경관리·구성관리·인시던트관리와 연계되어 관리되었는가? [2-3-나-1-03]
- 배포 결과와 변경요청 간 추적성 확인
- 배포 후 발생한 인시던트·문제 이력 확인
- 배포 파일, 설정파일, 버전정보, 구성관리대장 최신화 여부
## 2. 테스트 지원 결과 확인
- 01. 운영 반영 전 테스트 지원이 계획대로 수행되었는가? [2-3-나-2-01]
- 기능시험, 회귀시험, 통합시험, 사용자 확인시험 지원 결과 확인
- 테스트 환경, 테스트 데이터, 계정·권한 제공 여부 확인
- 테스트 수행자, 지원자, 승인자 이력 확인
- 02. 테스트 결함 조치와 재검증이 완료되었는가? [2-3-나-2-02]
- 결함 목록, 등급, 담당자, 조치기한 관리 여부
- 결함 조치 후 재시험 결과 확인
- 중대 결함 미조치 상태에서 운영 반영된 사례 여부 확인
- 03. 테스트 결과가 운영 반영 승인 근거로 활용되었는가? [2-3-나-2-03]
- 테스트 결과서, 사용자 확인서, 운영 반영 승인서 확인
- 주요 업무기능, 배치, 연계 기능 검증 결과 확인
- 테스트 결과와 배포 승인 간 정합성 확인
## 3. 장애관리 결과 확인
- 01. 개발SW 장애가 정의된 절차에 따라 접수·분석·조치되었는가? [2-3-나-3-01]
- 애플리케이션 오류, 배치 오류, 연계 오류, 화면 오류 처리 이력 확인
- 장애등급, 접수경로, 조치시간, 보고기준 준수 여부
- 중대장애 발생 시 긴급보고 및 escalation 수행 여부
- 02. 장애 원인분석과 재발방지 조치가 수행되었는가? [2-3-나-3-02]
- 임시조치와 근본조치 구분 관리 여부
- 반복장애의 문제관리 전환 여부
- 재발방지 대책 수립 및 조치 결과 확인
- 03. 장애 처리 결과가 업무부서 및 사용자에게 적정하게 공유되었는가? [2-3-나-3-03]
- 장애 조치 후 정상성 검증 여부
- 사용자 공지, 업무부서 확인, 장애 종료 승인 여부
- 장애 이력의 운영보고 반영 여부
