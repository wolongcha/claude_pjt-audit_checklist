# Table 13
- 도메인: 1. 클라우드 전환 사업
- 단계: 3. 종료 단계
- 카테고리: 가. 사업관리 및 품질보증

## 1. 과업 이행 및 범위 완료 확인
- 01. 계약·제안·요구사항 기준의 클라우드 전환 과업이 완료되었는가? [1-3-가-1-01]
- RFP, 제안서, 계약서, 요구사항정의서 대비 과업 이행 여부
- 클라우드 전환 대상 시스템, 서비스, 인프라, 데이터, 연계 범위 완료 여부
- 과업 누락, 미완료, 제외, 보류 항목 식별 여부
- 02. 변경 또는 추가 과업이 승인된 범위 내에서 완료되었는가? [1-3-가-1-02]
- 변경요청서, 승인내역, 반영결과 확인
- 변경에 따른 일정·비용·품질 영향 반영 여부
- 승인되지 않은 임의 변경 또는 구두 변경 여부
- 03. 전환 제외 또는 미완료 항목에 대한 후속 조치계획이 마련되어 있는가? [1-3-가-1-03]
- 제외 대상과 제외 사유 명확화 여부
- 잔여 과업의 조치 일정, 담당자, 승인자 정의 여부
- 운영 중 조치가 필요한 항목의 위험도 검토 여부
## 2. 일정 및 진척 완료 관리
- 01. 종료단계 기준으로 전체 전환 일정이 계획 대비 완료되었는가? [1-3-가-2-01]
- 요구정의, 설계, 구축, 테스트, 전환, 안정화 일정 완료 여부
- 지연 항목과 지연 사유 정리 여부
- 지연에 따른 서비스 오픈·운영 영향 분석 여부
- 02. 종료단계 주요 마일스톤과 승인 절차가 완료되었는가? [1-3-가-2-02]
- 통합테스트 완료, 데이터 이관 완료, 보안점검 완료, 서비스 오픈 승인 여부
- Go/No-Go 판단 결과와 승인 근거 확보 여부
- 단계 종료 승인회의 또는 검수회의 수행 여부
- 03. 잔여 일정과 후속 안정화 일정이 관리되고 있는가? [1-3-가-2-03]
- 안정화 기간, 기술지원 기간, 하자보수 또는 후속 조치 일정 확인
- 운영 이관 이후 잔여 이슈 처리 계획 수립 여부
- 완료 기준과 종료 기준 간 불일치 여부
## 3. 산출물 완전성 및 품질 확인
- 01. 종료단계 필수 산출물이 누락 없이 작성·승인되었는가? [1-3-가-3-01]
- 완료보고서, 전환결과보고서, 테스트결과서, 이관결과서 작성 여부
- 보안점검결과서, 성능시험결과서, 운영전환계획서, 인수인계서 작성 여부
- 산출물별 작성자, 검토자, 승인자 확인
- 02. 최종 산출물 간 내용의 일관성과 정합성이 확보되어 있는가? [1-3-가-3-02]
- 시스템명, IP, 구성정보, 계정, 포트, 연계정보 일치 여부
- 설계서, 구축결과서, 테스트결과서, 운영매뉴얼 간 불일치 여부
- 변경 이력이 최종 산출물에 반영되었는지 확인
- 03. 산출물이 운영 가능한 수준으로 구체화되어 있는가? [1-3-가-3-03]
- 운영자가 활용 가능한 절차, 기준, 담당자, 연락체계 포함 여부
- 장애·변경·백업·복구·보안·모니터링 절차 포함 여부
- 운영조직 검토 및 승인 여부
## 4. 요구사항 충족 및 추적성 확인
- 01. 요구사항별 최종 이행 여부가 검증되었는가? [1-3-가-4-01]
- 요구사항 추적표 기준 이행 완료 여부
- 미충족, 부분 충족, 대체 충족 항목 식별 여부
- 미충족 요구사항의 조치계획 및 승인 여부
- 02. 요구사항–설계–구축–테스트–검수 간 추적성이 확보되어 있는가? [1-3-가-4-02]
- 요구사항별 설계 반영, 구축 결과, 테스트 결과 매핑 여부
- 테스트 미수행 또는 검증 누락 요구사항 존재 여부
- 검수 기준과 요구사항 간 정합성 확인
- 03. 요구사항 변경 사항이 최종 결과에 반영되었는가? [1-3-가-4-03]
- 변경요청별 승인·반영·검증 결과 확인
- 변경사항이 관련 산출물과 테스트 항목에 반영되었는지 확인
- 변경 미반영 항목의 후속 조치계획 확인
## 5. 통합테스트 및 결함 조치 확인
- 01. 사용자 환경 기반 통합테스트가 계획대로 수행되었는가? [1-3-가-5-01]
- 주요 업무 시나리오 기반 통합시험 수행 여부
- 애플리케이션, 데이터, 연계, 네트워크, 보안 포함 여부
- 테스트 결과와 합격 기준 충족 여부
- 02. 테스트 결함이 조치되고 재검증되었는가? [1-3-가-5-02]
- 결함 목록, 등급, 담당자, 조치기한 관리 여부
- 중대·치명 결함 조치 완료 여부
- 조치 후 재시험 및 승인 결과 확보 여부
- 03. 미조치 결함 또는 보류 결함의 운영 영향이 검토되었는가? [1-3-가-5-03]
- 미조치 결함의 사유와 위험도 분석 여부
- 운영 중 조치계획, 담당자, 완료기한 정의 여부
- 오픈 승인 시 보류 결함 수용 여부 확인
## 6. 서비스 전환 및 안정화 확인
- 01. 서비스 전환이 승인 기준에 따라 정상 완료되었는가? [1-3-가-6-01]
- 서비스 오픈 조건과 Go/No-Go 기준 충족 여부
- 오픈 승인자, 승인일시, 승인 근거 확보 여부
- 오픈 후 핵심 업무 정상성 확인 여부
- 02. 서비스 안정화 활동이 적정하게 수행되었는가? [1-3-가-6-02]
- 안정화 기간, 지원 인력, 비상연락망 운영 여부
- 장애·문의·결함 접수 및 처리 현황 관리 여부
- 안정화 종료 기준과 종료 승인 여부
- 03. 애플리케이션 및 상용SW 기술지원이 적정하게 제공되고 있는가? [1-3-가-6-03]
- 상용SW 공급사, CSP/MSP, 수행사 기술지원 체계 확인
- 장애 발생 시 지원 절차와 조치 이력 확인
- 기술지원 종료 후 운영조직 대응 가능성 확인
## 7. 운영 인수인계 및 운영준비 확인
- 01. 운영조직에 필요한 산출물과 운영정보가 인계되었는가? [1-3-가-7-01]
- 구성도, 계정·권한, IP·포트, 연계정보, 운영매뉴얼 인계 여부
- 백업·복구 절차, 장애대응 절차, 변경관리 절차 인계 여부
- 인수인계 확인서와 운영조직 승인 여부
- 02. 운영조직이 클라우드 전환 결과를 운영할 준비가 되어 있는가? [1-3-가-7-02]
- 운영자 교육, 관리자 교육, 보안교육 수행 여부
- 운영도구, 모니터링, 접근권한, 보고체계 준비 여부
- 운영조직의 미숙지 또는 운영 공백 위험 확인
## 8. 위험·이슈 및 잔여사항 관리
- 01. 종료단계 기준 잔여 위험과 이슈가 식별되어 있는가? [1-3-가-8-01]
- 미해결 결함, 보안 예외, 성능 미달, 운영 미숙 항목 식별 여부
- 잔여 위험별 영향도, 담당자, 조치기한 정의 여부
- 운영 전환 후 추적관리 방안 마련 여부
- 02. 장애·결함·이슈 조치 이력이 관리되고 있는가? [1-3-가-8-02]
- 이슈 목록, 조치 내역, 조치 결과, 승인 이력 확인
- 반복 장애 또는 재발 이슈에 대한 원인분석 여부
- 재발방지 대책 수립 여부
- 03. 운영 중 조치가 필요한 항목이 공식적으로 인계되었는가? [1-3-가-8-03]
- 잔여 이슈 인수인계서 작성 여부
- 운영조직, 수행사, CSP/MSP 간 조치 책임 명확화 여부
- 후속 조치 완료 확인 체계 수립 여부
## 9. 검수 및 단계 종료 승인
- 01. 검수 기준에 따라 최종 검수가 수행되었는가? [1-3-가-9-01]
- 검수 기준, 검수 항목, 검수 증적 확보 여부
- 과업 완료, 산출물 완료, 시험 완료, 이관 완료 확인 여부
- 검수 결과와 보완 요청사항 관리 여부
- 02. 단계 종료 또는 사업 종료 승인 근거가 확보되었는가? [1-3-가-9-02]
- 완료보고서, 감리 조치결과, 검수확인서 등 승인자료 확보 여부
- 미완료 항목에 대한 조건부 승인 여부 확인
- 종료 승인권자와 승인 절차 확인
- 03. 감리 지적사항과 시정조치가 완료되었는가? [1-3-가-9-03]
- 감리 지적사항별 조치계획과 조치결과 확인
- 미조치 사항의 사유와 후속 조치계획 확인
- 시정조치 확인 증적 확보 여부
