## 1. 현행 인프라 구성 파악
- 01. 현행 시스템의 인프라 구성과 운영환경이 충분히 파악되어 있는가? [1-1-마-1-01]
- 서버, 스토리지, 네트워크, 백업, 보안장비 구성 현황 확인
- 물리서버, 가상서버, OS, 미들웨어, DBMS 설치 위치 확인
- 운영계·개발계·검증계·DR 환경 구성 현황 확인
- 02. 현행 인프라 자원 사용량과 성능 현황이 분석되어 있는가? [1-1-마-1-02]
- CPU, 메모리, 디스크, IOPS, 네트워크 사용량 확인
- 사용자 수, 동시접속자 수, 트랜잭션량, 배치 처리량 확인
- 피크 시간대, 월말·연말 등 특수 부하 현황 확인
## 2. 전환 대상 인프라 식별
- 01. 클라우드 전환 대상 인프라가 누락 없이 식별되어 있는가? [1-1-마-2-01]
- 전환 대상 서버, VM, 스토리지, DB 서버, Web/WAS 서버 식별 여부
- 배치 서버, 연계 서버, 관리 서버, 백업 서버 포함 여부
- 전환 대상 인프라 목록과 업무시스템 간 매핑 여부
- 02. 전환 제외 대상과 제외 사유가 명확히 정의되어 있는가? [1-1-마-2-02]
- 전환 제외 서버, 장비, 솔루션, 전용장비 식별 여부
- 제외 사유와 제약조건 명시 여부
- 제외 대상이 전체 전환 구조와 운영에 미치는 영향 검토 여부
- 03. 인프라별 중요도와 전환 우선순위가 정의되어 있는가? [1-1-마-2-03]
- 핵심 업무, 대민 서비스, 내부 업무별 중요도 분류 여부
- 보안등급, 가용성 요구수준, 업무 영향도 반영 여부
- 단계적 전환 또는 일괄 전환 기준 확인
## 3. 클라우드 전환 가능성 검토
- 01. 현행 인프라와 목표 클라우드 인프라 간 차이가 분석되어 있는가? [1-1-마-3-01]
- 물리환경과 가상화·클라우드 환경 간 구조 차이 확인
- 자원 할당 방식, 백업 방식, 모니터링 방식 차이 확인
- 운영관리 책임과 기술지원 방식 변화 확인
## 4. 목표 인프라 구성 요구사항
- 01. 목표 클라우드 인프라 구성 요구사항이 명확하게 정의되어 있는가? [1-1-마-4-01]
- 서버, 스토리지, 네트워크, 보안, 백업, 모니터링 요구사항 정의 여부
- Web, WAS, DB, 배치, 연계, 관리서버별 자원 요구사항 정의 여부
- 개발·검증·운영·DR 환경별 구성 요구사항 구분 여부
- 02. 목표 인프라 구성과 업무 요구사항 간 정합성이 확보되어 있는가? [1-1-마-4-02]
- 업무 처리량과 자원규모 간 적정성 확인
- 업무 연속성, 확장성, 보안 요구사항 반영 여부
- 운영조직이 관리 가능한 구성인지 검토 여부
## 5. 시스템 구성 및 사용량 확정
- 01. 최적의 성능과 안정성 확보를 위한 시스템 구성 및 사용조건이 정의되어 있는가? [1-1-마-5-01]
- 사용자 수, 동시접속자 수, 트랜잭션량 산정 여부
- 배치 처리량, 파일 처리량, 데이터 증가량 반영 여부
- 업무 피크, 월말·연말 처리, 대량 처리 조건 반영 여부
- 02. 인프라 자원 산정 기준이 정량적으로 제시되어 있는가? [1-1-마-5-02]
- vCPU, 메모리, 스토리지, IOPS, 네트워크 대역폭 산정 기준 확인
- 현행 사용량과 목표 사용량 비교 여부
- 향후 증가량과 확장 필요성 반영 여부
- 03. 자원 사용조건과 운영 제약사항이 명확히 정의되어 있는가? [1-1-마-5-03]
- 자원 사용 한계, 서비스 제약, 기술 제약 확인
- 사용량 급증 시 증설 또는 확장 기준 확인
## 6. 컴퓨팅 자원 요구사항
- 01. 컴퓨팅 자원 요구사항이 업무 처리량에 맞게 정의되어 있는가? [1-1-마-6-01]
- 서버별 vCPU, 메모리, 인스턴스 수량 산정 여부
- 업무별 자원 할당 기준과 우선순위 확인
- 운영계·개발계·검증계 자원 규모 구분 여부
- 02. 컴퓨팅 자원의 확장·축소 요구사항이 정의되어 있는가? [1-1-마-6-02]
- 수평확장, 수직확장 적용 필요성 검토 여부
- 오토스케일링 적용 대상과 기준 검토 여부
- 자원 증설·축소 승인 절차 요구사항 확인
## 7. 스토리지 및 저장소 요구사항
- 01. 스토리지 구성 요구사항이 데이터 특성에 맞게 정의되어 있는가? [1-1-마-7-01]
- 블록, 파일, 오브젝트 스토리지 적용 필요성 검토 여부
- DB 데이터, 첨부파일, 로그, 백업 데이터별 저장소 요구사항 정의 여부
- 용량, IOPS, 처리량, 지연시간 기준 확인
- 02. 스토리지 용량과 증가율이 반영되어 있는가? [1-1-마-7-02]
- 현행 데이터 용량과 향후 증가량 산정 여부
- 로그, 백업, 임시파일, 아카이브 데이터 용량 반영 여부
- 용량 부족 시 증설 기준과 절차 정의 여부
- 01. 스토리지 보안 및 접근 요구사항이 정의되어 있는가? [1-1-마-7-01]
- 저장구간 암호화, 접근권한, 보관·삭제 기준 확인
- 중요 데이터 저장소의 접근통제 요구사항 확인
- 스토리지 장애 및 복구 요구사항 확인
## 8. 백업·복구 요구사항
- 01. 클라우드 인프라의 백업·복구 요구사항이 명확하게 정의되어 있는가? [1-1-마-8-01]
- 서버, DB, 파일, 설정정보, 로그에 대한 백업 대상 정의 여부
- 백업 주기, 보관기간, 보관위치, 백업 방식 정의 여부
- 백업 실패 시 알림 및 재수행 기준 확인
- 02. RTO/RPO 등 복구 목표가 정의되어 있는가? [1-1-마-8-02]
- 업무별 RTO, RPO, 복구 우선순위 확인
- 복구 절차와 복구 승인 기준 정의 여부
- 복구 가능성 검증을 위한 시험 요구사항 확인
- 03. 장애 또는 전환 실패에 대비한 원복 요구사항이 정의되어 있는가? [1-1-마-8-03]
- 전환 전 백업 기준 확인
- 원복 시점, 원복 절차, 원복 책임자 정의 여부
- 원복 후 서비스 정상성 검증 기준 확인
## 9. 고가용성 및 이중화 요구사항
- 01. 주요 인프라 구성요소의 가용성 요구사항이 정의되어 있는가? [1-1-마-9-01]
- 서버, DB, 스토리지, 네트워크, 보안장비 이중화 필요성 확인
- Load Balancer, 다중 Zone, 이중 회선 적용 필요성 확인
- 업무 중요도별 가용성 수준 차등 적용 여부
- 02. 단일 장애점 제거 요구사항이 도출되어 있는가? [1-1-마-9-02]
- 단일 서버, 단일 회선, 단일 스토리지 위험 식별 여부
- SPOF 제거 또는 보완대책 요구사항 확인
- 제거 불가 항목의 예외 사유와 대응방안 정의 여부
## 10. 네트워크 연계 요구사항
- 01. 클라우드 인프라와 내·외부 시스템 간 네트워크 연결 요구사항이 식별되어 있는가? [1-1-마-10-01]
- 내부 업무망, 인터넷망, 관리망, 외부기관 연계 요구사항 확인
- 온프레미스, 공통기반, 운영관리망 연결 요구사항 확인

## 11. 성능 요구사항
- 01. 클라우드 전환 후 애플리케이션 성능 요구사항이 정량적으로 정의되어 있는가? [1-1-마-11-01]

## 12. 인프라 보안 요구사항
- 01. 클라우드 인프라 보안 요구사항이 충분히 정의되어 있는가? [1-1-마-12-01]
