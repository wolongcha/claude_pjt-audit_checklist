## 2. RAG 아키텍처 및 검색 생성 흐름 설계

- 사용자 질의 → 검색 → 근거 선택 → 생성 → 응답 흐름 정의

- 검색 실패, 근거 부족, 생성 실패 시 예외처리 흐름 설계
- 02. 검색과 생성 단계가 분리 검증 가능하도록 설계되었는가? [3-2-나-2-02]

- 검색 정확도와 생성 정확도 평가를 위한 추적정보 설계
- 검색 오류와 생성 오류 원인분석 가능성 확보
- 03. 근거 기반 응답 생성 구조가 반영되었는가? [3-2-나-2-03]

- 출처, 문서명, 조항, 작성일 등 근거 표시 설계
- 근거 없는 응답 제한 및 답변불가 처리 설계
