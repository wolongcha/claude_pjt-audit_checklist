## 1. 유지관리 수행결과 확인
- 01. 개발SW 유지관리 과업이 계획과 절차에 따라 수행되었는가? [2-3-라-1-01]
- 유지관리 요청 접수, 분석, 승인, 수정, 테스트, 배포, 종료 절차가 수행되었는지 확인
- 오류수정, 기능개선, 성능개선, 데이터 수정 요청별 처리결과 확인
- 정기 유지관리와 긴급 유지관리 수행 이력 및 승인 이력 확인
- 02. 운영과 유지관리 간 업무 인계 및 처리 결과가 적정한가? [2-3-라-1-02]
- 운영 중 발생한 장애가 유지관리 요청으로 전환된 이력 확인
- 단순문의, 장애, 오류수정, 기능개선 간 분류 기준 준수 여부 확인
- 운영팀, 유지관리팀, 업무부서 간 요청 이관 및 결과확인 이력 확인
## 2. CSR 처리 결과 확인
- 01. CSR 처리 결과가 기준에 따라 관리되었는가? [2-3-라-2-01]
- CSR 접수, 분류, 우선순위, 영향도 분석, 승인 이력 확인
- 오류수정, 기능변경, 데이터 정정, 업무지원 요청별 처리결과 확인
- CSR 처리기한, 승인권자, 종료 기준, 사용자 확인 기준 준수 여부 확인
- 02. CSR 처리 결과의 추적성이 확보되어 있는가? [2-3-라-2-02]
- 요청사항과 수정 소스, 테스트 결과, 배포 결과 간 추적성 확인
- 미처리·보류·반려 요청의 사유와 후속 조치계획 확인
- 처리결과가 운영보고 및 SLA/성과지표에 반영되었는지 확인
## 3. 프로그램 수정 및 테스트 결과 확인
- 01. 프로그램 수정 결과가 적정하게 검증되었는가? [2-3-라-3-01]
- 수정 대상 기능, 화면, 배치, 연계 프로그램의 변경 이력 확인
- 소스 수정 기준, 개발표준, 보안코딩 기준 준수 여부 확인
- 긴급수정 시 사전·사후 승인 절차 준수 여부 확인
- 02. 수정 프로그램에 대한 테스트와 사용자 확인이 완료되었는가? [2-3-라-3-02]
- 단위시험, 통합시험, 회귀시험, 사용자 확인시험 결과 확인
- 수정 기능과 영향 기능에 대한 테스트 수행 여부 확인
- 결함 조치, 재시험, 승인 결과 확인
## 4. 형상·
배포관리 결과 확인
- 01. 수정 프로그램의 형상관리와 배포관리가 적정하게 수행되었는가? [2-3-라-4-01]
- 소스, 설정파일, 배포파일, 라이브러리 버전관리 결과 확인

- 형상 변경 이력과 승인 이력 관리 여부 확인
- 02. 릴리스 및 배포 결과가 정상적으로 관리되었는가? [2-3-라-4-02]
- 정기배포, 긴급배포, 임시배포 수행 이력 확인

- 배포 후 정상성 점검 및 배포 결과보고서 확인
## 5. 성능·장애 개선 결과 확인
- 01. 개발SW 성능개선 및 반복장애 개선이 수행되었는가? [2-3-라-5-01]

- 02. 반복 장애에 대한 재발방지 조치가 완료되었는가? [2-3-라-5-02]
