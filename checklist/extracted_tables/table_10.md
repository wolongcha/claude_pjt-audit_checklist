# Table 10
- 도메인: 1. 클라우드 전환 사업
- 단계: 2. 설계 단계
- 카테고리: 라. 데이터 복제 및 동기화

## 1. 복제·동기화 대상 정의
- 01. 복제 및 동기화 대상 데이터가 명확히 식별되어 있는가? [1-2-라-1-01]
- 복제 대상 DB, 테이블, 파일, 로그, 기준정보, 트랜잭션 데이터 식별 여부
- 실시간 동기화 대상과 배치 동기화 대상 구분 여부
- 복제 제외 대상과 제외 사유 명시 여부
- 02. 업무 중요도에 따라 복제 우선순위가 정의되어 있는가? [1-2-라-1-02]
- 핵심 업무 데이터, 공통코드, 사용자 정보, 거래 데이터 우선순위 정의 여부
- 서비스 오픈 필수 데이터와 사후 반영 가능 데이터 구분 여부
- 중요 데이터 누락 시 업무 영향도 분석 여부
- 03. 복제 대상 데이터와 애플리케이션·연계시스템 간 관계가 정의되어 있는가? [1-2-라-1-03]
- 애플리케이션 기능별 필요 데이터 매핑 여부
- 연계시스템에서 참조하는 데이터 포함 여부
- 기준정보와 트랜잭션 데이터 간 선후행 관계 반영 여부
## 2. 복제·동기화 방식 설계
- 01. 데이터 특성에 맞는 복제·동기화 방식이 설계되어 있는가? [1-2-라-2-01]
- DB 복제, CDC, 로그 기반 복제, ETL, API, 파일 동기화 방식 검토 여부
- 실시간, 준실시간, 주기적 배치 동기화 방식 구분 여부
- 데이터량, 변경 빈도, 업무 중요도에 따른 방식 차등 적용 여부
- 02. 복제 방향과 구조가 명확히 설계되어 있는가? [1-2-라-2-02]
- 단방향 복제, 양방향 복제, Active
- Standby, Active
- Active 구조 정의 여부
- 원천 DB와 대상 DB 간 역할 및 책임 구분 여부
- 복제 중단 또는 전환 시점의 데이터 기준점 정의 여부
- 03. 초기 적재와 변경분 동기화 절차가 구분되어 설계되어 있는가? [1-2-라-2-03]
- 초기 Full Load 절차 정의 여부
- 초기 적재 이후 변경분 반영 방식 정의 여부
- 초기 적재와 변경분 동기화 간 중복·누락 방지 기준 정의 여부
## 3. 복제 기준시점 및 동기화 주기 설계
- 01. 복제 기준시점과 동기화 주기가 업무 요구에 맞게 정의되어 있는가? [1-2-라-3-01]
- 기준시점, 스냅샷 시점, Cutover 기준시점 정의 여부
- 동기화 주기, 허용 지연시간, 반영 지연 한계 정의 여부
- 업무중단 시간과 동기화 완료 시간 간 정합성 검토 여부
- 02. RPO 요구사항과 동기화 설계가 일치하는가? [1-2-라-3-02]
- 데이터 손실 허용 범위 정의 여부
- 복제 지연이 RPO 목표를 초과하지 않는지 검토 여부
- 장애 또는 전환 시점의 데이터 복구 기준 정의 여부
- 03. 동기화 지연 발생 시 대응 기준이 마련되어 있는가? [1-2-라-3-03]
- 지연 임계치, 알림 기준, 조치 기준 정의 여부
- 지연 발생 시 우선 반영 데이터 기준 정의 여부
- 지연 해소 후 정합성 재검증 절차 반영 여부
## 4. 복제 아키텍처 및 구성 설계
- 01. 복제·동기화 아키텍처가 목표 클라우드 구조에 맞게 설계되어 있는가? [1-2-라-4-01]
- 원천 시스템, 복제 솔루션, 중계 서버, 대상 DB 구성 정의 여부
- 클라우드 네트워크, 보안그룹, 방화벽 정책과의 연계 설계 여부
- 운영환경, 검증환경, DR 환경 간 복제 구조 구분 여부
- 02. 복제 솔루션 또는 도구 구성요소가 상세 설계되어 있는가? [1-2-라-4-02]
- 복제 에이전트, 로그 리더, 중계 모듈, 큐, 모니터링 구성 정의 여부
- 복제 대상별 설정값, 접속정보, 권한, 계정 정의 여부
- 솔루션 장애 시 재기동·재처리 절차 반영 여부
- 03. 복제 구성의 단일 장애점이 식별되고 제거되었는가? [1-2-라-4-03]
- 중계 서버, 네트워크 구간, 스토리지, 대상 DB SPOF 검토 여부
- 복제 솔루션 자체 이중화 필요성 검토 여부
- 장애 시 복제 재개 또는 대체 경로 설계 여부
## 5. 데이터 매핑 및 변환 설계
- 01. 원천 데이터와 대상 데이터 간 매핑 기준이 정의되어 있는가? [1-2-라-5-01]
- 테이블·컬럼 단위 매핑 정의 여부
- 데이터 타입, 길이, 문자셋, 코드값, 날짜 형식 차이 반영 여부
- 매핑 불가 항목과 예외 처리 기준 정의 여부
- 02. 복제 과정의 데이터 변환·정제 기준이 설계되어 있는가? [1-2-라-5-02]
- 코드 변환, 형식 변환, 암호화·복호화 적용 기준 정의 여부
- 오류값, 누락값, 중복값 처리 기준 반영 여부
- 변환 후 업무적 의미가 유지되는지 검증 기준 정의 여부
- 03. 스키마 변경 시 복제 영향 관리 방안이 마련되어 있는가? [1-2-라-5-03]
- 테이블·컬럼 추가·변경·삭제 시 복제 설정 변경 절차 정의 여부
- 스키마 변경에 따른 애플리케이션 영향 검토 여부
- 변경 후 복제 재검증 기준 반영 여부
## 6. 정합성 검증 설계
- 01. 복제 전후 데이터 정합성 검증 기준이 구체적으로 설계되어 있는가? [1-2-라-6-01]
- 건수, 합계, 키값, 상태값, 참조관계 비교 기준 정의 여부
- 테이블별·업무별·중요 데이터별 검증 수준 차등 적용 여부
- 정합성 불일치 허용 기준과 예외 승인 기준 정의 여부
- 02. 실시간 또는 주기적 정합성 점검 방안이 마련되어 있는가? [1-2-라-6-02]
- 복제 상태 모니터링과 정합성 점검 주기 정의 여부
- 체크섬, 해시, 샘플링, 증분 비교 등 검증 방식 반영 여부
- 정합성 오류 발생 시 자동 탐지 및 알림 기준 정의 여부
## 7. 충돌 및 중복 처리 설계
- 01. 양방향 또는 병행 운영 시 데이터 충돌 처리 기준이 마련되어 있는가? [1-2-라-7-01]
- 동일 데이터 동시 변경 시 우선순위 기준 정의 여부
- 원천 우선, 최신 변경 우선, 업무 승인 기반 처리 등 정책 정의 여부
- 충돌 발생 시 알림, 보류, 수작업 승인 절차 반영 여부
- 02. 중복 반영 및 누락 방지 방안이 설계되어 있는가? [1-2-라-7-02]
- 변경분 식별 키, 타임스탬프, 로그 시퀀스 관리 여부
- 재처리 시 중복 반영 방지 기준 정의 여부
- 누락 데이터 탐지 및 보정 절차 반영 여부
- 03. 복제 실패 후 재처리 기준이 정의되어 있는가? [1-2-라-7-03]
- 실패 구간 재시작, 부분 재처리, 전체 재처리 기준 정의 여부
- 재처리 후 정합성 재검증 절차 반영 여부
- 반복 오류 원인분석 및 조치 기준 정의 여부
## 8. 성능 및 부하 영향 설계
- 01. 복제·동기화로 인한 원천 시스템과 대상 시스템의 성능 영향이 분석되었는가? [1-2-라-8-01]
- 원천 DB 로그 증가, CPU·메모리·I/O 부하 분석 여부
- 대상 DB 반영 부하, 인덱스 영향, Lock 발생 가능성 검토 여부
- 업무 피크 시간대 복제 부하 영향 검토 여부
- 02. 복제 처리 성능 기준이 정량적으로 정의되어 있는가? [1-2-라-8-02]
- 초당 처리 건수, 반영 지연시간, 큐 적체 허용 기준 정의 여부
- 대량 변경분 발생 시 처리 기준 반영 여부
- 성능 미달 시 튜닝·증설·분할 처리 방안 정의 여부
## 9. 모니터링 및 장애 대응 설계
- 01. 복제·동기화 상태를 모니터링할 수 있도록 설계되어 있는가? [1-2-라-9-01]
- 복제 상태, 지연시간, 큐 적체, 오류 건수 모니터링 항목 정의 여부
- 임계치, 알림 대상, 알림 방식 정의 여부
- 모니터링 결과 보고 주기와 담당자 정의 여부
- 02. 복제 장애 후 데이터 정합성 복구 절차가 설계되어 있는가? [1-2-라-9-02]
- 장애 구간 식별 및 변경분 재반영 기준 정의 여부
- 복구 후 정합성 검증 기준 반영 여부
- 장애 조치 결과와 재발방지 대책 관리 여부
## 10. 리허설 및 전환 검증 설계
- 01. 복제·동기화 리허설 계획이 구체적으로 설계되어 있는가? [1-2-라-10-01]
- 초기 적재, 변경분 동기화, 장애 복구 리허설 범위 정의 여부
- 리허설 일정, 데이터 규모, 담당자, 검증 기준 정의 여부
- 리허설 결과보고서와 보완 조치 기준 반영 여부
## 12. 산출물 및 증적관리
- 01. 복제·동기화 관련 산출물이 정의되어 있는가? [1-2-라-12-01]
- 복제설계서, 동기화계획서, 매핑정의서, 정합성 검증계획서 작성 여부
- 리허설 결과서, 복제 모니터링 결과, 오류 조치내역 산출물 정의 여부
- 산출물별 작성자, 검토자, 승인자 지정 여부
- 02. 복제 결과와 정합성 검증 결과가 증적으로 관리되도록 설계되어 있는가? [1-2-라-12-02]
- 복제 성공·실패 로그 보관 기준 정의 여부
- 정합성 비교 결과, 오류 목록, 조치 결과 관리 여부
- 최종 전환 승인 근거로 활용 가능한 증적 확보 여부
