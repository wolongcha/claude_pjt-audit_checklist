## 1. 플랫폼 구축 완료 확인
- 01. 클라우드 플랫폼 구성요소가 설계대로 구축 완료되었는가? [1-3-다-1-01]
- 컴퓨팅, 스토리지, 네트워크, 보안, 백업, 모니터링 구성 완료 여부
- IaaS, PaaS, SaaS 등 적용 대상 서비스 구성 완료 여부
- 설계서와 실제 플랫폼 구성 간 일치 여부
- 02. 운영·개발·검증·DR 등 환경별 플랫폼 구성이 정상 분리되어 있는가? [1-3-다-1-02]
- 환경별 프로젝트, 테넌트, VPC, 서브넷 분리 여부
- 운영환경과 비운영환경 간 접근통제 적용 여부
- 환경 간 구성정보, 권한, 데이터 혼재 여부 확인
- 03. 플랫폼 구성 변경사항이 최종 산출물에 반영되어 있는가? [1-3-다-1-03]
- 구축 중 변경된 자원, 네트워크, 보안정책 반영 여부
- 변경 승인 이력과 최종 구성정보 일치 여부
- 최신 구성도와 실제 운영환경 일치 여부
## 2. 플랫폼 서비스 이용환경 확인
- 01. 클라우드 정보자원을 효율적으로 이용할 수 있는 환경이 정상 구축되었는가? [1-3-다-2-01]
- 프로젝트, 테넌트, 계정, 권한, 자원그룹 설정 완료 여부
- 자원 신청, 승인, 할당, 변경, 회수 절차 적용 여부
- 운영자 콘솔 또는 관리 포털 사용 가능 여부
- 02. 플랫폼 공통서비스가 정상 동작하는가? [1-3-다-2-02]
- Load Balancer, DNS, API Gateway, DBaaS, 메시징 등 공통서비스 정상 여부
- 백업, 모니터링, 로그관리, 보안관리 서비스 정상 여부
- 서비스별 적용 대상 시스템과 실제 연결 상태 확인
- 03. 플랫폼 자원 사용 현황을 운영자가 확인·관리할 수 있는가? [1-3-다-2-03]
- 자원 상태, 사용량, 장애, 성능 현황 조회 가능 여부
- 운영조직의 관리 권한 부여 여부
- CSP/MSP와 운영조직 간 관리 범위 명확화 여부
