## 1. 과업 이행 및 범위 완료 확인
- 01. 운영 및 유지관리 과업이 계약·제안·요구사항 범위대로 이행되었는가? [2-3-가-1-01]
- 개발SW 운영, 인프라 운영, 개발SW 유지관리, 상용SW 유지관리, 인프라 유지관리 과업 수행 여부 확인
- RFP, 제안서, 계약서, 과업지시서 대비 미수행·부분수행·초과수행 항목 확인
- 정기점검, 장애처리, 변경처리, 패치, 배포, 기술지원 등 주요 활동 수행 여부 확인
- 02. 과업 제외·보류·미완료 항목이 명확히 관리되고 있는가? [2-3-가-1-02]
- 미완료 과업의 사유, 영향도, 후속 조치계획 확인
- 운영상 위험이 있는 보류 항목의 대응방안 확인
- 조건부 완료 또는 후속 유지관리 이관 항목의 승인 여부 확인
## 2. SLA 및 서비스수준 달성 확인
- 01. 운영 및 유지관리 SLA가 목표 수준을 충족하였는가? [2-3-가-2-01]
- 가용성, 장애처리시간, 복구시간, 응답시간, CSR 처리기한 등 SLA 실적 확인
- 개발SW 운영, 인프라 운영, 유지관리 활동별 SLA 달성률 확인
- SLA 미달 항목의 원인분석 및 개선조치 여부 확인
- 02. SLA 측정 결과와 보고자료가 신뢰성 있게 관리되었는가? [2-3-가-2-02]
- SLA 측정 기준, 측정 원천, 측정 주기, 산정 방식 확인
- 월간·분기·수시 운영보고서와 SLA 실적 간 정합성 확인
- 서비스수준 미달 또는 예외 처리 내역의 승인 여부 확인
- 01. 서비스수준 개선 활동이 수행되었는가? [2-3-가-2-01]
- 반복 장애, 성능 저하, 처리지연 항목에 대한 개선조치 확인
- 개선조치 후 재측정 및 효과 확인 여부
- 개선 필요사항의 차기 운영·유지관리 계획 반영 여부
## 3. 일정 및 수행실적 확인
- 01. 운영 및 유지관리 주요 활동이 계획된 일정에 따라 수행되었는가? [2-3-가-3-01]
- 정기점검, 예방점검, 보안점검, 패치, 백업점검, 성능점검 수행실적 확인
- 정기배포, 긴급배포, 릴리스 수행실적 확인
- 계획 대비 지연·누락·미수행 활동 확인
- 02. 일정 지연 또는 미수행 활동에 대한 조치가 적정한가? [2-3-가-3-02]
- 지연 사유, 영향도, 조치계획, 승인 여부 확인
- SLA, 장애대응, 보안위험, 서비스 안정성에 미친 영향 검토
- 후속 조치 완료 여부와 잔여 위험 확인
- 03. 외부 공급사 또는 상용SW 제조사 지원 일정이 적정하게 이행되었는가? [2-3-가-3-03]
- 공급사 기술지원 요청 및 처리 이력 확인
- 패치, 업그레이드, 장애지원, 재설치 지원 결과 확인
- 공급사 지원 지연 또는 미지원 항목의 후속 조치 여부 확인
## 4. 산출물 완전성 및 품질 확인
- 01. 운영 및 유지관리 산출물이 누락 없이 작성·승인되었는가? [2-3-가-4-01]
- 운영계획서, 유지관리계획서, SLA 관리표, 장애관리대장, 변경관리대장 확인
- 정기점검보고서, 월간운영보고서, 패치결과서, 배포결과서, 보안점검결과서 확인
- 산출물별 작성자, 검토자, 승인자, 제출주기 준수 여부 확인
- 02. 산출물 내용이 실제 수행결과와 일치하는가? [2-3-가-4-02]
- 운영보고서와 장애·변경·CSR·배포 이력 간 정합성 확인
- 점검보고서와 실제 조치결과 간 불일치 여부 확인
- 산출물 최신본 관리 및 버전관리 여부 확인
- 03. 품질보증 활동 결과가 적정하게 관리되었는가? [2-3-가-4-03]
- 정기 품질점검, 산출물 리뷰, 운영성과 점검 수행 여부 확인
- 품질 미흡사항의 조치 및 재확인 여부 확인
- 품질보증 결과가 최종 완료판단에 반영되었는지 확인
## 5. 운영성과 및 개선관리 확인
- 01. 운영성과 지표가 측정·분석되었는가? [2-3-가-5-01]
- 장애건수, 장애처리시간, SLA 달성률, CSR 처리율, 사용자 만족도 측정 여부 확인
- 운영, 유지관리, 보안, 품질 영역별 성과지표 관리 여부 확인
- 월간·분기·연간 성과보고서 작성 여부 확인
- 02. 지속개선 과제가 도출되고 관리되었는가? [2-3-가-5-02]
- 반복장애, 성능저하, 사용자 불편사항의 개선과제화 여부 확인
- 개선과제 우선순위, 담당자, 일정, 승인 기준 확인
- 개선조치 결과와 효과 측정 여부 확인
- 03. 성과분석 결과가 차기 운영·유지관리 계획에 반영되는가? [2-3-가-5-03]
- 개선 필요사항의 후속 조치계획 수립 여부 확인
- SLA·품질·보안 개선사항의 차기 계획 반영 여부 확인
- 운영성과 기반 계약·인력·일정 조정 필요성 검토 여부 확인
## 6. 인수인계 및 종료관리 확인
- 01. 운영 및 유지관리 종료 또는 다음 단계 인수인계가 적정하게 수행되었는가? [2-3-가-6-01]
- 잔여 이슈, 미처리 CSR, 보류 변경사항 인계 여부 확인
- 산출물, 구성정보, 계정·권한, 운영지식 인계 여부 확인
- 운영조직 또는 차기 수행사 인수 확인 여부 확인
- 02. 운영지식과 기술이전이 충분히 이루어졌는가? [2-3-가-6-02]
- 운영자 교육, 기술이전, 매뉴얼 제공 여부 확인
- 장애대응, 변경관리, 배포관리, 보안조치 수행 방법 인계 여부 확인
- 상용SW 공급사 및 인프라 기술지원 연락체계 인계 여부 확인
- 03. 감리 지적사항 및 시정조치가 완료되었는가? [2-3-가-6-03]
- 감리 지적사항별 조치계획과 조치결과 확인
- 미조치 사항의 사유와 후속 조치계획 확인
- 시정조치 확인 증적 확보 여부 확인
