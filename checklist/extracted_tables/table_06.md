## 1. 네트워크 전환 범위 식별
- 01. 클라우드 전환에 따른 네트워크 변경 대상과 범위가 명확하게 식별되어 있는가? [1-1-바-1-01]
- 내부망, 외부망, 업무망, 관리망, 인터넷망 등 전환 영향 범위 확인
- 온프레미스–클라우드 간 연결 필요 구간 식별 여부
- 전환 제외 네트워크 구간과 제외 사유 확인
- 02. 네트워크 변경이 필요한 시스템과 서비스가 누락 없이 식별되어 있는가? [1-1-바-1-02]
- 업무시스템, 연계시스템, 관리시스템, 보안시스템 식별 여부
- 사용자 접속, 관리자 접속, 외부기관 접속 경로 식별 여부
- 클라우드 전환으로 영향받는 통신 구간 확인
- 03. 네트워크 전환 범위와 애플리케이션·인프라·데이터 전환 범위가 일치하는가? [1-1-바-1-03]
- 전환 대상 시스템과 네트워크 연결 대상 간 정합성 확인
- 데이터 이관·복제 구간의 네트워크 요구사항 반영 여부
- 연계시스템 변경 범위와 네트워크 변경 범위 일치 여부
## 2. 현행 네트워크 구성 파악
- 01. 현행 네트워크 구성과 접속 구조가 충분히 파악되어 있는가? [1-1-바-2-01]
- 현행 네트워크 구성도, IP 대역, VLAN, 서브넷, 라우팅 정보 확인
- 방화벽, L4/L7, VPN, 전용회선, 보안장비 구성 현황 확인
- 내부망·외부망·관리망·연계망 간 연결 구조 확인
## 3. 목표 네트워크 구성 요구사항
- 01. 클라우드 환경의 목표 네트워크 구성 요구사항이 명확하게 정의되어 있는가? [1-1-바-3-01]

- 운영·개발·검증·DR 환경별 네트워크 분리 요구사항 확인
- 02. 클라우드와 기존 환경 간 연결 방식이 검토되어 있는가? [1-1-바-3-02]
- 전용회선, VPN, Peering, 보안터널 적용 필요성 검토
- 연결 구간별 대역폭, 지연시간, 가용성 요구사항 확인
- 회선 장애 시 우회경로 또는 대체 접속 방식 검토 여부
