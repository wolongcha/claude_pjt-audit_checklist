## 1. 복제·동기화 완료 확인
- 01. 복제 및 동기화 대상 데이터가 계획된 범위대로 반영 완료되었는가? [1-3-라-1-01]
- 복제 대상 DB, 테이블, 파일, 로그, 기준정보, 트랜잭션 데이터 반영 여부
- 복제 제외 또는 보류 대상의 사유와 후속 조치계획 확인
- 복제 대상 목록과 실제 운영환경 데이터 구성 간 일치 여부
- 02. 초기 적재와 변경분 동기화가 정상 완료되었는가? [1-3-라-1-02]
- 초기 Full Load 완료 여부
- 초기 적재 이후 변경분 반영 여부
- 중복·누락 없이 최종 동기화가 완료되었는지 확인
- 03. 복제·동기화 결과가 최종 전환 기준시점과 일치하는가? [1-3-라-1-03]
- Cutover 기준시점의 데이터 반영 여부
- 최종 변경분 반영 완료 여부
- 기준시점 이후 불필요한 추가 변경 또는 누락 여부 확인
## 2. 복제 상태 및 지연 확인
- 01. 복제·동기화 상태가 정상으로 확인되었는가? [1-3-라-2-01]
- 복제 프로세스, 에이전트, 중계서버, 대상 DB 상태 확인
- 복제 성공·실패 로그 확인
- 복제 중단, 오류, 재시작 이력 확인
- 02. 복제 지연 시간이 허용 기준 내에 있는가? [1-3-라-2-02]
- 실시간 또는 준실시간 동기화 지연시간 확인
- 큐 적체, 로그 적체, 반영 대기 건수 확인
- 지연 발생 시 조치 및 재검증 결과 확인
## 3. 데이터 정합성 검증 확인
- 01. 복제 전후 데이터 정합성이 검증되었는가? [1-3-라-3-01]
- 원천·대상 데이터 간 건수, 합계, 주요 값 비교 여부
- 테이블별, 업무별, 중요 데이터별 정합성 검증 결과 확인
- 정합성 검증 결과보고서와 승인 이력 확보 여부
- 02. 체크섬, 해시, 샘플링 등 기술적 검증 결과가 적정한가? [1-3-라-3-02]
- 대용량 데이터에 대한 해시·체크섬 비교 수행 여부
- 전체 검증 또는 샘플 검증 적용 기준 준수 여부
- 불일치 항목의 원인분석 및 조치 결과 확인
- 03. 업무 검증을 통해 복제 데이터의 사용 가능성이 확인되었는가? [1-3-라-3-03]
- 업무 담당자 검증 수행 여부
- 주요 화면, 배치, 연계, 보고서에서 복제 데이터 정상 사용 여부
- 업무 검증 결과와 승인 증적 확보 여부
## 4. 변경분 반영 및 누락 확인
- 01. 운영 중 발생한 변경분이 누락 없이 동기화되었는가? [1-3-라-4-01]
- Insert, Update, Delete 변경분 반영 여부
- 로그 시퀀스, 타임스탬프, 변경 키 기준 반영 결과 확인
- 미반영 또는 누락 변경분 존재 여부 확인
- 02. 재처리 과정에서 중복 반영이 발생하지 않았는가? [1-3-라-4-02]
- 재처리 대상 데이터의 중복 여부 확인
- 동일 거래, 동일 키, 동일 이벤트의 중복 반영 여부 확인
- 중복 데이터 조치 결과와 재검증 결과 확인
- 03. 변경분 반영 실패 건이 조치되고 재검증되었는가? [1-3-라-4-03]
- 실패 건수, 실패 원인, 조치 담당자 관리 여부
- 부분 재처리 또는 전체 재처리 결과 확인
- 재처리 후 정합성 재검증 수행 여부
## 5. 충돌 및 예외 데이터 처리 확인
- 01. 양방향 또는 병행 운영 중 발생한 데이터 충돌이 적정하게 처리되었는가? [1-3-라-5-01]
- 동일 데이터 동시 변경 충돌 발생 여부
- 충돌 처리 기준에 따른 조치 여부
- 충돌 처리 결과의 업무 승인 여부
- 02. 예외 데이터가 기준에 따라 관리되고 있는가? [1-3-라-5-02]
- 예외 데이터 목록, 발생 사유, 처리 상태 확인
- 보정, 제외, 수작업 처리, 재처리 기준 준수 여부
- 예외 승인 이력과 후속 조치계획 확인
## 6. 복제 성능 및 부하 검증 확인
- 01. 복제·동기화 성능이 목표 기준을 충족하였는가? [1-3-라-6-01]
- 초당 처리 건수, 반영 지연시간, 큐 적체 기준 충족 여부
- 평상시·피크·대량 변경 상황별 성능 확인
- 성능 미달 항목의 조치 및 재시험 여부
## 7. 복제 모니터링 및 운영관리 확인
- 01. 복제·동기화 상태를 운영 중 모니터링할 수 있는가? [1-3-라-7-01]
- 복제 상태, 지연시간, 큐 적체, 오류 건수 모니터링 여부
- 임계치, 알림 기준, 담당자 지정 여부
- 모니터링 대시보드 또는 리포트 제공 여부
- 02. 복제 상태 보고와 이력관리가 가능하도록 구성되었는가? [1-3-라-7-02]
- 일일·주간 복제상태 보고 기준 확인
- 복제 성공·실패 이력 보관 기준 확인
- 장애 및 조치 이력의 감사증적 확보 여부
## 8. Cutover 및 복제 종료 확인
- 01. 서비스 전환 시점에 최종 동기화가 완료되었는가? [1-3-라-8-01]
- Cutover 직전 최종 변경분 반영 완료 여부
- 복제 지연 0 또는 허용 범위 내 확인 여부
- 최종 정합성 검증 후 오픈 승인 여부
- 02. 전환 후 원천·대상 시스템의 역할 전환이 정상적으로 이루어졌는가? [1-3-라-8-02]
- 기존 원천 시스템과 신규 클라우드 시스템의 역할 정리 여부
- 읽기·쓰기 기준 전환 여부
- 전환 후 이중 입력 또는 중복 처리 발생 여부
## 9. 통합테스트 및 업무 정상성 확인
- 01. 복제·동기화 데이터 기반 통합테스트가 수행되었는가? [1-3-라-9-01]
- 복제 데이터 기반 주요 업무 시나리오 테스트 수행 여부
- 조회, 등록, 수정, 삭제, 승인, 배치 처리 정상 여부
- 통합테스트 결과와 정합성 검증 결과 간 불일치 여부
- 02. 업무 담당자 또는 운영조직의 최종 확인이 완료되었는가? [1-3-라-9-02]
- 업무 검증 결과서 또는 사용자 확인서 확보 여부
- 중요 업무별 데이터 정상성 승인 여부
- 보류 항목의 운영 영향과 후속 조치계획 확인
## 10. 산출물 및 증적 확인
- 01. 복제·동기화 관련 최종 산출물이 완비되었는가? [1-3-라-10-01]
- 복제설계서, 동기화계획서, 매핑정의서 최종본 확보 여부
- 정합성 검증결과서, 리허설 결과서, 복제 결과보고서 작성 여부
- 산출물별 검토·승인 이력 확인
- 02. 복제 결과와 정합성 검증 결과가 증적으로 확보되었는가? [1-3-라-10-02]
- 복제 성공·실패 로그 보관 여부
- 정합성 비교 결과, 오류 목록, 조치 결과 확보 여부
- 최종 전환 승인 근거로 활용 가능한 증적 확보 여부
- 03. 감리 지적사항 및 시정조치가 완료되었는가? [1-3-라-10-03]
- 복제·동기화 관련 감리 지적사항 조치 결과 확인
- 미조치 사항의 사유와 후속 조치계획 확인
- 시정조치 확인 증적 확보 여부
## 11. 운영 인수인계 확인
- 01. 복제·동기화 운영에 필요한 정보가 운영조직에 인계되었는가? [1-3-라-11-01]
- 복제 구성정보, 계정·권한, 접속정보, 모니터링 기준 인계 여부
- 복제 오류 대응 절차, 재처리 절차, 정합성 점검 방법 인계 여부
- 복제 솔루션 또는 도구 운영 매뉴얼 인계 여부
- 02. 잔여 위험과 후속 조치사항이 공식 인계되었는가? [1-3-라-11-02]
- 복제 지연 가능성, 미조치 오류, 예외 데이터 인계 여부
- 운영 중 정기 정합성 점검 필요 항목 정의 여부
- 후속 조치 담당자, 완료기한, 추적관리 기준 확인
