## 1. 클라우드 플랫폼 적용 범위 정의
- 01. 클라우드 플랫폼 적용 대상과 범위가 명확하게 정의되어 있는가? [1-1-다-1-01]
- IaaS, PaaS, SaaS 적용 대상 식별 여부
- 플랫폼 적용 대상 업무·시스템·서비스 범위 정의 여부
- 플랫폼 전환 대상과 제외 대상 구분 여부
- 02. 플랫폼 적용 방식이 업무 특성과 전환 목적에 부합하는가? [1-1-다-1-02]
- 정부 클라우드, 민간 클라우드, 하이브리드 적용 여부 검토
- 업무 중요도, 보안등급, 서비스 특성 반영 여부
- 전환 목적과 플랫폼 적용 효과 간 정합성 확인
- 03. 플랫폼 적용 제외 또는 제한 대상에 대한 사유가 명확한가? [1-1-다-1-03]
- 레거시 시스템, 특수장비, 전용솔루션 등 제외 대상 확인
- 제외 사유와 후속 조치계획 확인
- 제외 대상이 전체 전환 구조에 미치는 영향 검토
## 2. 클라우드 서비스 유형 및 제공모델 정의
- 01. 클라우드 서비스 유형이 요구사항에 맞게 정의되어 있는가? [1-1-다-2-01]
- IaaS, PaaS, SaaS, DBaaS 등 서비스 유형 검토 여부
- 업무별 적용 서비스 유형 결정 기준 확인
- 서비스 유형별 책임 범위와 운영 방식 검토
- 02. CSP/MSP 등 서비스 제공자 역할이 명확하게 정의되어 있는가? [1-1-다-2-02]
- CSP, MSP, 수행사, 발주기관 간 책임분계 확인
- 플랫폼 운영, 장애 대응, 보안관리 역할 구분 여부
- 서비스 제공자의 기술지원 범위 검토 여부
## 3. 플랫폼 기본 구성 요구사항
- 01. 클라우드 플랫폼에서 제공해야 할 기본 구성 요구사항이 정의되어 있는가? [1-1-다-3-01]
- 컴퓨팅, 스토리지, 네트워크, 보안, 백업 요구사항 정의 여부
- 모니터링, 로그관리, 계정관리, 권한관리 요구사항 포함 여부
- 운영관리 포털 또는 콘솔 사용 요구사항 정의 여부
- 02. 업무시스템별 플랫폼 구성 요구사항이 구분되어 있는가? [1-1-다-3-02]
- 운영계, 검증계, 개발계, DR 환경별 구성 요구사항 정의 여부
- 핵심 업무와 일반 업무의 자원 분리 기준 확인
- 업무 중요도별 가용성·성능 기준 차등 적용 여부
- 03. 플랫폼 공통서비스 요구사항이 식별되어 있는가? [1-1-다-3-03]
- Load Balancer, DNS, API Gateway, 메시징 등 필요성 검토
- 백업, 모니터링, 로그관리, 보안관리 공통기능 정의 여부
- 공통서비스별 적용 대상과 사용 목적 확인
## 4. 시스템 구성 및 사용조건 확정
- 01. 최적의 성능과 안정성 확보를 위한 시스템 구성 및 사용조건이 정의되어 있는가? [1-1-다-4-01](원본에 대괄호 ID 누락 — 같은 그룹 02번 항목의 [1-1-다-4-02]와 번호 패턴으로 추정 보완)
- 사용자 수, 동시접속자 수, 트랜잭션량 산정 여부
- 서버, 스토리지, 네트워크, 보안 자원 규모 정의 여부
- 업무 피크, 월말·연말 처리, 대량 배치 조건 반영 여부
- 02. 플랫폼 자원 산정 기준이 정량적으로 제시되어 있는가? [1-1-다-4-02]
- vCPU, 메모리, 스토리지, IOPS, 네트워크 대역폭 기준 확인
- 현행 사용량과 목표 사용량 비교 여부
- 향후 증가량과 확장 필요성 반영 여부
## 5. 플랫폼 아키텍처 요구사항
- 01. 클라우드 플랫폼 목표 아키텍처 요구사항이 정의되어 있는가? [1-1-다-5-01]

## 6. 플랫폼 이용환경 요구사항
- 01. 클라우드 정보자원을 효율적으로 이용하기 위한 이용환경 요구사항이 정의되어 있는가? [1-1-다-6-01](원본에 대괄호 ID 누락 — 같은 그룹 02번 항목의 [1-1-다-6-02]와 번호 패턴으로 추정 보완)

- 운영자 콘솔 또는 관리 포털 사용 요구사항 확인
- 02. 플랫폼 계정과 권한 체계가 정의되어 있는가? [1-1-다-6-02]

- 01. 클라우드 플랫폼과 내·외부 시스템 간 연계 요구사항이 식별되어 있는가? [1-1-다-7-01]
- 기존 시스템, 외부기관, 공통기반, 인증체계 연계 대상 확인
- 보안관제, 통합로그, 운영관리 시스템 연계 필요성 확인
- API, 파일, DB, 메시징 연계 방식 검토
- 02. 플랫폼 접속 및 트래픽 처리 요구사항이 정의되어 있는가? [1-1-다-7-02]
