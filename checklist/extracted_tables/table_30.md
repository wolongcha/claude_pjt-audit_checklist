## 1. 유지관리 수행절차 설계
- 01. 인프라 유지관리 절차가 대상별로 구체화되어 있는가? [2-2-바-1-01]
- 서버, 스토리지, 네트워크, DB, 보안장비, 백업장비별 유지관리 절차가 반영되어 있는지 확인
- 정기점검, 장애처리, 패치, 부품교체, 설정변경, 기술지원 절차가 설계되어 있는지 확인
- 운영업무와 유지관리업무 간 경계 및 인계 기준이 반영되어 있는지 확인
## 2. 정기·
예방점검 설계
- 01. 인프라 정기점검 및 예방점검 절차가 설계되어 있는가? [2-2-바-2-01]
- 서버, DB, 네트워크, 스토리지, 보안장비별 점검항목이 반영되어 있는지 확인
- 점검 주기, 점검 담당자, 결과보고, 승인 절차가 설계되어 있는지 확인
- 장애징후, 성능저하, 용량부족, 보안위험 탐지 기준이 반영되어 있는지 확인
## 3. 장애·
성능·용량관리 설계
- 01. 인프라 장애·성능·용량관리 절차가 설계되어 있는가? [2-2-바-3-01]
- 장애 등급, 접수경로, 조치시간, 보고체계가 반영되어 있는지 확인
- CPU, 메모리, 디스크 I/O, 네트워크, DB 성능지표와 임계치가 설계되어 있는지 확인
- 디스크, 스토리지, DB, 로그, 백업 용량 임계치와 증설 기준이 설계되어 있는지 확인
## 4. 백업·복구 및 가용성 설계
- 01. 백업·복구 및 가용성 유지관리 절차가 설계되어 있는가? [2-2-바-4-01]
- 백업 대상, 백업 주기, 보관기간, 보관 위치가 반영되어 있는지 확인
- 백업 실패 시 알림 및 재수행 절차가 설계되어 있는지 확인
- 이중화, 장애전환, DR 연계, RTO/RPO, 복구 우선순위 기준이 반영되어 있는지 확인
## 5. 구성·
변경·보안 유지관리 설계
- 01. 인프라 구성·변경·보안 유지관리 절차가 설계되어 있는가? [2-2-바-5-01]
- 서버, 네트워크, DB, 보안장비 구성정보 관리 항목이 반영되어 있는지 확인
- 변경요청, 영향도 분석, 승인, 반영, 검증, 종료 절차가 설계되어 있는지 확인
- 계정권한, 접근통제, 보안패치, 취약점 조치, 작업로그 관리 기준이 반영되어 있는지 확인
