## 1. 인프라 유지관리 수행결과 확인
- 01. 인프라 유지관리 과업이 대상별로 적정하게 수행되었는가? [2-3-바-1-01]
- 서버, 스토리지, 네트워크, DB, 보안장비, 백업장비별 유지관리 결과 확인
- 정기점검, 장애처리, 패치, 부품교체, 설정변경, 기술지원 수행 결과 확인
- 운영업무와 유지관리업무 간 인계 및 처리결과 확인
- 02. 인프라 중요도에 따른 우선순위와 대응절차가 준수되었는가? [2-3-바-1-02]
- 핵심 서버, 주요 DB, 대외서비스 장비, 보안장비 우선지원 결과 확인
- 장애 발생 시 업무 영향도 기반 조치 우선순위 준수 여부 확인
- 우선 복구 대상과 우선 기술지원 대상 처리 결과 확인
## 2. 정기·예방 점검 결과 확인
- 01. 인프라 정기점검 및 예방점검이 계획대로 수행되었는가? [2-3-바-2-01]
- 서버, DB, 네트워크, 스토리지, 보안장비별 점검결과 확인
- 점검 주기, 점검 담당자, 결과보고, 승인 절차 준수 여부 확인
- 장애징후, 성능저하, 용량부족, 보안위험 탐지 결과 확인
- 02. 점검 결과에 따른 개선조치가 수행되었는가? [2-3-바-2-02]
- 점검 결과 이상 항목의 조치계획 및 조치결과 확인
- 반복 이상 징후의 문제관리 전환 여부 확인
- 조치 결과의 운영보고 및 개선과제 반영 여부 확인
## 3. 장애·성능
·용량관리 결과 확인
- 01. 인프라 장애관리가 기준에 따라 수행되었는가? [2-3-바-3-01]
- 장애 등급, 접수경로, 조치시간, 보고체계 준수 여부 확인
- 서버, DB, 네트워크, 스토리지, 보안장비별 장애처리 결과 확인
- 중대장애 발생 시 비상연락망과 escalation 수행 여부 확인
- 02. 인프라 성능 및 용량관리가 적정하게 수행되었는가? [2-3-바-3-02]
- CPU, 메모리, 디스크 I/O, 네트워크, DB 성능지표 관리 결과 확인
- 성능 임계치 초과, 알림, 조치 결과 확인
- 디스크, 스토리지, DB, 로그, 백업 용량 임계치 및 증설 결과 확인
## 4. 백업·복구 및 가용성 결과 확인
- 01. 백업·복구 유지관리가 적정하게 수행되었는가? [2-3-바-4-01]
- 백업 대상, 백업 주기, 보관기간, 보관 위치 준수 여부 확인
- 백업 실패 시 알림 및 재수행 결과 확인
- 복구시험 수행 결과 및 결과보고서 확인
- 02. 가용성 유지관리와 장애전환 검증이 수행되었는가? [2-3-바-4-02]
- 이중화, 장애전환, 클러스터, DR 연계 대상 관리 결과 확인
- 장애전환 시험 및 복구 검증 결과 확인
- RTO/RPO, 복구 우선순위 기준 충족 여부 확인
## 5. 구성·변경
·보안 유지관리 결과 확인
- 01. 인프라 구성정보 및 변경관리가 적정하게 수행되었는가? [2-3-바-5-01]
- 서버, 네트워크, DB, 보안장비 구성정보 최신화 여부 확인
- 구성 변경 시 구성관리대장 또는 CMDB 갱신 여부 확인
- 변경요청, 영향도 분석, 승인, 반영, 검증, 종료 이력 확인
- 02. 인프라 보안 유지관리가 적정하게 수행되었는가? [2-3-바-5-02]
- 계정권한, 접근통제, 보안패치, 취약점 조치 결과 확인
- 보안로그, 작업로그, 접속로그 관리 결과 확인
- 외부 유지관리 인력 접근통제 및 작업승인 이력 확인
## 6. 공급사·
부품·기술지원 결과 확인
- 01. 인프라 공급사 및 기술지원이 계약조건에 따라 수행되었는가? [2-3-바-6-01]
- 장비 공급사, 유지관리사, 통신사, 클라우드 사업자 지원 결과 확인
- 장애지원, 부품교체, 긴급출동, 기술문의 요청 처리 결과 확인
- 공급사 지원시간, 응답시간, 조치기한 준수 여부 확인
- 02. 부품교체 및 장비수리 결과가 적정하게 관리되었는가? [2-3-바-6-02]
- 예비부품 확보, 교체 승인, 교체 후 정상성 검증 결과 확인
- 장비수리 또는 교체 시 서비스 영향도 분석 여부 확인
- 부품교체 이력과 구성정보 갱신 여부 확인
