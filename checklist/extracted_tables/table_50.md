- 외부 LLM 호출 제한 기준 및 예외처리 적용 여부

## 2. RAG 기능 구현 및 검색-생성 흐름 검증
- 01. RAG 처리 흐름이 정상 동작하는가? [3-3-나-2-01]
- 사용자 질의 → 검색 → 근거 선택 → 생성 → 응답 흐름 정상 여부
- 검색 결과와 생성 응답 간 데이터 전달 정상 여부
- 검색 실패, 근거 부족, 생성 실패 시 예외처리 동작 여부
- 02. 검색과 생성 단계가 분리 검증 가능한가? [3-3-나-2-02]
- 검색 결과 로그 및 생성 결과 로그 분리 저장 여부
- 검색 오류와 생성 오류의 원인분석 가능 여부
- 검색·생성별 성능 및 품질 측정 결과 확보 여부
- 03. 근거 기반 응답 생성이 구현되었는가? [3-3-나-2-03]
- 응답 내 근거 문서, 출처, 조항, 작성일 표시 여부
- 근거 문서와 응답 내용 간 일치성 확인
- 근거 없는 응답 제한 및 답변불가 처리 동작 여부
## 3. 하이브리드 검색 및 랭킹 결과 검증
- 01. 하이브리드 검색이 요구사항대로 동작하는가? [3-3-나-3-01]
- 키워드 검색과 벡터 검색 병행 적용 여부
- 메타정보 검색과 내용 기반 검색 결합 결과 확인
- 검색 방식별 결과 비교 및 통합 결과 적정성 확인
- 02. 검색 랭킹 및 재정렬 결과가 적정한가? [3-3-나-3-02]
- Top-K 검색 결과 적합성 확인
- Re-ranking 결과의 관련도 및 우선순위 적정성 확인
- 중복 문서, 노이즈 문서, 부적절 검색결과 제거 여부
- 03. 검색 실패 및 예외상황 처리가 정상 동작하는가? [3-3-나-3-03]
- Zero-hit 발생 시 안내 및 보완 질의 처리 여부
- 과다 검색 시 상세조건 요청 및 멀티턴 처리 여부
- 검색 오류 발생 시 사용자 안내 및 로그 기록 여부
## 4. 청킹·
임베딩 및 벡터DB 품질 검증
- 01. 청킹 결과가 문서 특성에 맞게 적용되었는가? [3-3-나-4-01]
- 기록물, 민원, 사규 등 문서 유형별 청킹 결과 확인
- 조항·문단·첨부파일의 의미 단위 유지 여부
- 청킹 크기, 중첩, 문맥 보존 수준 검증
- 02. 임베딩 품질이 검색 품질을 충족하는가? [3-3-나-4-02]
- 대표 질의 기반 유사도 검색 결과 검증
- 임베딩 모델 적용 결과의 업무 적합성 확인
- 임베딩 재생성 및 변경관리 절차 적용 여부
- 03. 벡터DB 적재 및 현행화가 정상적으로 수행되었는가? [3-3-나-4-03]
- 벡터DB 적재 성공률 및 누락 데이터 확인
- 메타데이터, 권한정보, 문서번호, 작성일 등 필터정보 적재 여부
- 재색인, 삭제, 갱신 처리 결과 확인
## 5. AI 응답 품질 및 할루시네이션 검증
- 01. AI 응답 품질이 기준을 충족하는가? [3-3-나-5-01]
- 답변 정확성, 완전성, 일관성, 이해가능성 검증
- 대민 민원 답변, 내부 지식검색, 문서생성 결과 품질 확인
- 응답 템플릿 및 문체 기준 준수 여부
- 02. 할루시네이션 통제가 정상적으로 작동하는가? [3-3-나-5-02]
- 근거 문서 미존재 시 답변 제한 동작 확인
- 근거와 응답 간 불일치 사례 검증
- 추정 표현, 불확실성 안내, 담당자 확인 유도 적용 여부
- 03. 오답 및 부정확 응답 관리체계가 운영 가능한가? [3-3-나-5-03]
- 오답 신고, 오류 유형 분류, 개선 이력관리 기능 확인
- 반복 오답 탐지 및 개선 프로세스 확인
- 품질저하 발생 시 운영자 알림 및 조치 절차 확인

## 9. AI 운영·모니터링 및 LLMOps 준비 검증

- 02. RAG 운영 모니터링이 가능한가? [3-3-나-9-02]
