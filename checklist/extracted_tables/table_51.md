## 1. Agentic AI 구현 완료 및 과업이행 점검
- 01. Agentic AI 기능이 요구사항대로 구현되었는가? [3-3-다-1-01]
- 업무별, 영역별 Agent 구현 여부
- 단일 Agent 및 다중 Agent 적용 범위 구현 여부
- Agent별 역할, 책임, 처리 범위의 최종 반영 여부
- 02. Agent 실행 흐름이 정상 동작하는가? [3-3-다-1-02]
- 사용자 요청 → 의도분석 → 계획수립 → Tool 호출 → 결과검증 → 응답 흐름 정상 여부
- Agent 실행 중단, 재시도, 예외처리 동작 여부
- Agent 실패 시 담당자 전환 또는 대체 처리 동작 여부
## 2. MCP Tool 연계 검증
- 01. MCP 기반 Tool 연계가 정상 구현되었는가? [3-3-다-2-01]
- MCP Server, MCP Client, Tool Registry 구성 적용 여부
- Agent별 호출 가능한 Tool 목록 및 권한 적용 여부
- Tool 입력값·출력값·호출조건·응답형식 준수 여부
- 02. MCP Tool 호출 통제가 정상 동작하는가? [3-3-다-2-02]
- 사용자 권한 기반 Tool 호출 제한 여부
- 민감정보 포함 요청의 Tool 호출 차단 여부
- 외부 API 또는 외부 LLM 연계 Tool 호출 시 보안통제 적용 여부
- 02. MCP 실행 로그 및 감사추적이 가능한가? [3-3-다-2-02]
- Tool 호출 이력, 파라미터, 응답값, 오류 로그 저장 여부
- Tool 호출 승인·차단·실패 이력 관리 여부
- 사고 발생 시 Tool 호출 경로 역추적 가능 여부
## 3. A2A 연계 및 Agent 간 협업 검증
- 01. Agent 간 통신 구조가 정상 동작하는가? [3-3-다-3-01]
- Agent 간 역할, 호출 순서, 메시지 형식 적용 여부
- 요청 Agent, 수행 Agent, 검증 Agent 간 데이터 전달 정상 여부
- Agent 간 책임 경계 및 처리 결과 구분 여부
- 02. A2A 호출 통제 및 충돌 방지가 적용되었는가? [3-3-다-3-02]
- 중복 호출, 무한 루프, 반복 실행 방지 기능 동작 여부
- Agent 간 상충 결과 발생 시 우선순위 적용 여부
- 호출 실패·지연·타임아웃 처리 결과 확인
- 03. A2A 결과 검증 및 책임추적이 가능한가? [3-3-다-3-03]
- Agent별 처리 결과와 최종 응답 간 정합성 확인
- Agent 간 호출 이력 및 의사결정 경로 기록 여부
- 최종 응답 생성 책임 Agent 식별 가능 여부
## 4. Agent–RAG 연계 검증
- 01. Agent와 RAG 검색 연계가 정상 동작하는가? [3-3-다-4-01]
- Agent의 RAG 대상 데이터 및 검색 범위 호출 정상 여부
- 기록물관리, 민원통합, 사규, FAQ별 검색 호출 결과 확인
- 검색 결과가 Agent 응답에 정상 반영되는지 확인
- 02. 검색 결과 검증 및 근거 활용이 적정한가? [3-3-다-4-02]
- Agent가 활용한 근거 문서의 출처 표시 여부
- 관련도 낮은 검색 결과 제외 여부
- 근거 부족 시 추가질의 또는 답변 제한 동작 여부
## 5. Agent–Tool/API 결과 검증
- 01. Agent가 호출하는 Tool/API가 정상 동작하는가? [3-3-다-5-01]
- 내부 업무시스템 API, 검색 API, 문서생성 Tool, 외부 API 호출 정상 여부
- Tool별 입력값, 출력값, 호출조건 준수 여부
- Agent별 허용 Tool 목록과 실제 호출 결과 일치 여부
- 02. Tool 호출 결과 검증이 수행되는가? [3-3-다-5-02]
- Tool 응답값의 유효성 검증 적용 여부
- Tool 호출 실패, 지연, 중복 호출 대응 결과 확인
- Tool 결과와 Agent 응답 간 정합성 확인
## 6. 계획 수립 및 실행 통제 검증
- 01. Agent의 계획 수립 및 실행 로직이 정상 동작하는가? [3-3-다-6-01]
- 사용자 요청을 처리 단계로 분해하는 동작 확인
- 다단계 업무 수행 시 실행 순서 및 조건 준수 여부
- 계획 변경, 중단, 재시도 처리 결과 확인
- 02. Agent의 자율 실행 범위가 통제되는가? [3-3-다-6-02]
- 자동 실행 가능 업무와 승인 필요 업무 구분 적용 여부
- 민원 접수, 외부 전송, 문서 확정 등 사용자 승인 지점 동작 여부
- 고위험 업무의 자동처리 제한 적용 여부
## 7. Agent 보안 및 권한 검증
- 01. Agent 실행 권한이 정상 적용되는가? [3-3-다-7-01]
- 사용자·부서·직무별 Agent 사용 권한 적용 여부
- Agent별 접근 가능한 데이터 및 Tool 범위 통제 여부
- 관리자·운영자·일반사용자 권한 분리 적용 여부
- 02. Agent 오남용 방지 기능이 동작하는가? [3-3-다-7-02]
- 권한 없는 데이터 조회 및 Tool 호출 차단 여부
- 프롬프트 인젝션에 의한 Tool 오용 차단 여부
- Agent 실행 횟수, 호출 빈도, 자원 사용 제한 적용 여부
- 03. Agent 실행 로그 및 감사추적이 확보되는가? [3-3-다-7-03]
- Agent 실행이력, Tool 호출이력, 사용자 승인 이력 기록 여부
- 오류·예외·보안 이벤트 로그 기록 여부
- 사고조사를 위한 실행 경로 추적 가능 여부
## 8. Human-in-the-Loop 검증
- 01. 사람 검토 및 승인 절차가 정상 동작하는가? [3-3-다-8-01]
- 민원 답변, 문서생성, 외부 전송 등 승인 필요 업무 처리 여부
- Agent 결과의 담당자 검토·수정·확정 절차 적용 여부
- 자동처리와 수동처리 전환 기준 동작 여부
- 02. Agent 실패 시 인간 개입 절차가 작동하는가? [3-3-다-8-02]
- 정보 부족, 권한 부족, 오류 발생 시 담당자 연결 여부
- 반복 실패 또는 민감 민원 발생 시 escalation 처리 여부
- 사용자 불만 및 오답 신고 처리 절차 동작 여부
## 9. Agent 품질 및 성능평가 검증
- 01. Agent 품질평가 결과가 기준을 충족하는가? [3-3-다-9-01]
- Agent 응답 정확성, 완전성, 일관성 평가 결과 확인
- 업무처리 결과와 근거 문서 간 정합성 검증
- 대민 서비스와 내부 업무 Agent 품질 기준 충족 여부
- 02. Agent 성능평가 결과가 적정한가? [3-3-다-9-02]
- Agent 응답시간, Tool 호출시간, 전체 처리시간 측정 결과 확인
- MCP Tool 호출 및 A2A 통신 지연시간 기준 충족 여부
- 성공률, 실패율, 재시도율, 사용자 만족도 지표 확인
## 10. Agent 운영 및 모니터링 검증
- 01. Agent 운영관리 체계가 준비되었는가? [3-3-다-10-01]
- Agent 등록·변경·배포·중지 절차 적용 여부
- Agent 버전관리 및 변경관리 적용 여부
- Agent별 담당자 및 운영 책임 지정 여부
- 02. Agent/MCP/A2A 모니터링이 가능한가? [3-3-다-10-02]
- Agent 실행 건수, 성공률, 실패율, 오류율 모니터링 여부
- MCP Tool 호출 성공률, 지연시간, 장애율 모니터링 여부
- A2A 호출 흐름, 반복 호출, 비정상 실행 탐지 여부
- 02. Agent 개선 및 재평가 체계가 마련되었는가? [3-3-다-10-02]
- 사용자 피드백 기반 Agent 개선 절차 확인
- 오답·실패 시나리오 재검토 및 개선 절차 확인
- 운영 중 Agent 성능 저하 탐지 및 재평가 기준 확인
## 11. Agent 산출물 및 증적관리 점검
- 01. Agent 관련 최종 산출물이 완비되었는가? [3-3-다-11-01]
- Agent 아키텍처 설계서, Agent 목록, 업무 시나리오 정의서 제출 여부
- MCP Tool/API 목록, 호출조건, 권한 매트릭스 제출 여부
- A2A 메시지 정의서, Agent 간 호출흐름도, 오류처리 기준 제출 여부
- 02. Agent 검증 증적이 확보되었는가? [3-3-다-11-02]
- Agent 실행 로그, MCP Tool 호출 로그, A2A 호출 로그 확보 여부
- 테스트 시나리오 및 수행결과 증적 확보 여부
- Agent 보안통제 및 권한검증 증적 확보 여부
## 12. 운영전환 및 잔여위험 관리
- 01. Agentic AI 운영전환 준비가 완료되었는가? [3-3-다-12-01]
- Agent 운영절차 및 장애 대응절차 인계 여부
- Agent별 운영 담당자 교육 및 권한 인계 여부
- Agent/MCP/A2A 운영 모니터링 기준선 확정 여부
- 02. 잔여위험 및 후속 개선과제가 정리되었는가? [3-3-다-12-02]
- Agent 오답, Tool 오류, A2A 충돌 등 잔여위험 식별 여부
- 운영 중 보완 필요사항 및 후속 개선과제 정리 여부
- 2·3차 확산을 위한 Agent 적용 기준 및 개선사항 정리 여부
