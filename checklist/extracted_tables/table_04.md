# Table 4
- 도메인: 1. 클라우드 전환 사업
- 단계: 1. 요구정의 단계
- 카테고리: 라. 데이터 복제 및 동기화

## 1. 데이터 전환 대상 식별
- 01. 클라우드 전환 대상 데이터가 누락 없이 식별되어 있는가? [1-1-라-1-01]
- 업무 DB, 테이블, 파일, 첨부파일, 로그, 기준정보, 이력 데이터 식별 여부
- 전환 대상 데이터와 제외 대상 데이터의 구분 여부
- 제외 대상 데이터의 사유와 후속 처리방안 정의 여부
- 02. 데이터 전환 대상과 업무·시스템 간 연관관계가 정의되어 있는가? [1-1-라-1-02]
- 업무 기능별 사용 데이터 매핑 여부
- 애플리케이션, 배치, 연계시스템에서 참조하는 데이터 식별 여부
- 기준정보, 마스터 데이터, 거래 데이터 간 선후행 관계 확인 여부
- 03. 현행 데이터 아키텍처가 충분히 파악되어 있는가? [1-1-라-1-03]
- 현행 DB 구조, 테이블 구조, 데이터 흐름, 연계 구조 파악 여부
- 데이터 발생·저장·활용·보관·폐기 흐름 확인 여부
- 현행 데이터 구조와 목표 클라우드 데이터 구조 간 차이 식별 여부
## 2. 데이터 전환 범위 및 기준 정의
- 01. 데이터 전환 범위가 업무 요구사항에 맞게 정의되어 있는가? [1-1-라-2-01]
- 전체 이관, 부분 이관, 기간별 이관, 업무별 이관 범위 정의 여부
- 운영 데이터, 과거 데이터, 로그 데이터, 첨부파일 포함 여부
- 전환 범위가 애플리케이션 전환 범위와 일치하는지 확인
## 3. 데이터 이관 방식 요구사항
- 01. 데이터 특성에 맞는 이관 방식이 검토되어 있는가? [1-1-라-3-01]
- DB Export/Import, ETL, 파일 이관, API 이관, DB 복제 방식 검토 여부
- 대용량 데이터, 첨부파일, 로그 데이터 등 유형별 이관 방식 구분 여부
- 업무중단 허용시간과 이관 방식 간 정합성 확인
## 4. 데이터 동기화 대상 및 필요성 검토
- 01. 클라우드 전환 과정에서 데이터 동기화가 필요한 대상이 식별되어 있는가? [1-1-라-4-01]
- 실시간 동기화 대상과 배치성 동기화 대상 구분 여부
- 운영 중 병행운영이 필요한 데이터 식별 여부
- 동기화 제외 대상과 제외 사유 정의 여부
- 02. 망간 또는 영역 간 데이터 동기화 필요성이 검토되었는가? [1-1-라-4-02]
- 행정망–인터넷망, 내부망–외부망, 운영망–DR망 간 데이터 전환·동기화 필요성 확인
- 망간 데이터 흐름, 보안통제, 승인 절차 식별 여부
- 데이터 동기화가 필요한 구간과 불필요한 구간 구분 여부
## 5. 동기화 방식 및 주기 요구사항
- 01. 데이터 특성에 맞는 동기화 방식이 검토되어 있는가? [1-1-라-5-01]
- CDC, 로그 기반 복제, DB 복제, ETL, API, 파일 동기화 방식 검토 여부
- 실시간, 준실시간, 배치성 동기화 방식 구분 여부
- 데이터량, 변경 빈도, 업무 중요도에 따른 방식 차등 적용 여부
- 02. 복제 방향과 운영 구조가 요구사항 단계에서 정의되어 있는가? [1-1-라-5-02]
- 단방향 복제, 양방향 복제, Active-Standby, Active-Active 구조 검토 여부
- 원천 시스템과 대상 시스템의 역할 정의 여부
- 병행운영 기간 중 데이터 입력·수정 기준 정의 여부
## 6. 원천·대상 데이터 매핑 및 변환 기준
- 01. 원천 데이터와 목표 클라우드 데이터 간 매핑 기준이 정의되어 있는가? [1-1-라-6-01]
- 테이블·컬럼 단위 매핑 정의 필요성 확인
- 데이터 타입, 길이, 문자셋, 코드값, 날짜 형식 차이 식별 여부
- 매핑 불가 항목과 예외 처리 기준 정의 여부
- 02. 데이터 변환·정제 기준이 요구사항에 포함되어 있는가? [1-1-라-6-02]
- 코드 변환, 형식 변환, 암호화·복호화 적용 기준 확인
- 오류값, 누락값, 중복값 처리 기준 확인
## 7. 데이터 정합성 검증 요구사항
- 01. 데이터 이관 전후 정합성 검증 기준이 정의되어 있는가? [1-1-라-7-01]
- 건수, 합계, 키값, 상태값, 참조관계 비교 기준 확인
- 테이블별·업무별·중요 데이터별 검증 수준 차등 적용 여부
- 정합성 검증 합격 기준과 예외 승인 기준 정의 여부
## 8. 오류·예외·충돌 처리 기준
- 01. 데이터 이관 오류와 예외 데이터 처리 기준이 정의되어 있는가? [1-1-라-8-01]
- 형식 오류, 코드 불일치, 누락값, 중복값 처리 기준 확인
- 보정, 제외, 재처리, 수작업 처리 기준 정의 여부
- 예외 데이터 승인 및 이력관리 기준 확인
## 9. 성능 및 부하 영향 요구사항
- 01. 데이터 이관 및 동기화로 인한 시스템 성능 영향이 검토되었는가? [1-1-라-9-01]
- 원천 DB CPU, 메모리, I/O, 로그 증가 영향 확인
- 대상 DB 반영 부하, Lock 발생, 인덱스 영향 검토 여부
- 업무 피크 시간대 이관·복제 부하 영향 분석 여부
## 10. 보안 및 개인정보 보호 요구사항
- 01. 데이터 이관·동기화 구간의 보안 요구사항이 정의되어 있는가? [1-1-라-10-01]
- 원천–대상 간 IP, 포트, 프로토콜, 방화벽 정책 식별 여부
- 전용회선, VPN, 보안그룹, 접근통제 적용 필요성 확인
- 망간 데이터 이동 시 승인·통제 절차 확인
## 11. 리허설· 전환 및 원복 요구사항
- 01. 데이터 이관·동기화 리허설 요구사항이 정의되어 있는가? [1-1-라-11-01]
- 초기 이관, 변경분 반영, 장애 복구 리허설 범위 정의 여부
- 리허설 일정, 데이터 규모, 담당자, 검증 기준 확인
- 리허설 결과보고서와 보완 조치 기준 반영 여부
## 12. 산출물 및 증적 요구사항
- 01. 데이터 전환 및 동기화 관련 산출물이 정의되어 있는가? [1-1-라-12-01]
- 데이터전환계획서, 이관대상정의서, 동기화계획서, 매핑정의서 작성 여부
- 정합성 검증계획서, 리허설계획서, 오류처리기준서 포함 여부
- 산출물별 작성자, 검토자, 승인자 지정 여부
